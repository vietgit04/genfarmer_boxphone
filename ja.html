はじめに

1週間コース - GenFarmer BoxPhone入門

1週間コースと、セットアップおよびソフトウェアの完全ガイドを1か所にまとめました。バージョン 1.1 · 09/2026。

5日間はシステムを使いこなすための期間であり、5日で成果が出るわけではありません。成果が出るまでには、2〜4週間のアカウントのウォームアップ（育成）が必要です。この2つはまったく別のマイルストーンです。最初にこれを理解しておけば、がっかりせずに済みます。

動画チュートリアルを見る サポートに問い合わせる

このドキュメントの構成について。1週間コースでは、作業の順序とそれぞれの理由を説明します。セットアップとソフトウェアには、スクリーンショット付きの詳しい手順をまとめています。そのため、コースは短く保たれ、手順を繰り返すことはありません。リファレンスは、何か問題が起きたときに開くページです。

はじめに

Boxphoneとは

ハードウェアそのものについて：ボックスの中身、主な用途、そしてボックスが棚に並べた単体のスマートフォンより優れている理由を説明します。

Boxphone（Box Phone Farmの略）は、数十〜数百枚のスマートフォンのメインボードを1つのコンパクトなボックスに収めて管理するハードウェアシステムです。多数のスマートフォンを個別に使う代わりに、主要な部品を1つのボックスに集約し、SNSプラットフォーム上の自動化タスクを実行します。

特長と構造

  • 最適化された設計：スマートフォンのメインボード（通常、火災の危険を防ぐために画面とバッテリーを取り外したもの）を、金属製の筐体の中に積み重ねたり並べたりして配置しています
  • 集中接続：ボックス内のすべてのデバイスが1本のケーブルでコンピューターに接続され、安定した電源供給を受けます
  • リモート操作：コンピューター上の1つのソフトウェアで、すべてのスマートフォンを同時に操作できます

主な用途

このシステムは、マーケティングやオンラインでの収益化に使われています。

  • エンゲージメントの人為的な増加：Facebook、TikTok、YouTubeでの「いいね」、シェア、コメント、動画再生数を増やし、人気があるように見せる効果を生み出します
  • アカウントの育成：大量のアカウントを管理し、実際のユーザーの行動をシミュレートしてBANを回避します
  • 広告と一斉メッセージ送信：グループへのメッセージ送信やコンテンツの投稿を行います
  • ゲームやアプリのファーミング：タスクを自動化して報酬を獲得します

ボックスが単体のスマートフォンより優れている理由

  • 省スペース：数百台のスマートフォン本体を並べるよりはるかにコンパクトです
  • 高い耐久性：連続充電時の主な発火原因であるバッテリーと画面を取り外しているため、システムの発熱が少なく、より安定して動作します
  • 一元管理：1つのソフトウェア画面からすべてを監視・保守できます

システム全体の中でボックスがどこに位置するかは、トップページで説明しています。

Change / SuperChangeとは

GenFarmer独自の技術：1台のデバイスを複数台に見せる仕組みと、Super Changeで追加される機能を説明します。

Changeとは

Changeは、AndroidデバイスのフィンガープリントをROMおよびハードウェアレベルで変更・エミュレートし、自動化用のデバイスを実際のユーザーのスマートフォンのように見せる技術です。一言で言えば、Changeはシステム上の識別情報の面で、1台のデバイスを複数の異なるデバイスに変えます。一部のBoxphoneモデルのROMにプリインストールされており、GenFarmerアプリケーション内でのみ動作します。

  • ADBの隠蔽：ADBは、Androidデバイスをリモートで操作するための通信チャネルです。Instagram、TikTok、Xなどのプラットフォームに検出されると、リーチの低下、シャドウバン、アカウント停止につながります。S8 ChangeはADBを隠し、デバイスを通常のスマートフォンのように見せます。
  • Android ROMのアップグレード：オリジナルのGalaxy S8はAndroid 9までしか対応しておらず、古いためにフラグを立てられやすくなります。S8 ChangeはROMをAndroid 14にアップグレードし、必要に応じてAndroid 12〜13に戻すこともできます。
  • 多様なフィンガープリント：ファーム全体で同じ機種、MACアドレス、フィンガープリントが並ぶと、検出されやすいパターンになります。S8 Changeは、代わりにOppo、Xiaomi、Huawei、Vivoなどのブランドをエミュレートできます。
  • リストアとバックアップ：ログイン状態などのアカウントデータは、デバイスの交換、リセット、移行後も保持されます。Change / Backup / Restoreをご覧ください。

SuperChangeとは

何年もスムーズに動き続けるように作られたマシンもあれば、すぐに性能が落ちるマシンもあります。その違いは価格ではなく、内部の設計にあります。Super Changeは、よく設計されたタイプです。スムーズに動作し、検出されにくい状態を保つよう、工場で構築・最適化されています。

  1. Change / Backup / Restore - 各デバイスに新しいアイデンティティとバックアップコピーが与えられ、運用を中断せずに数分でリストアできます。
  2. GPS - 位置情報のシミュレーション - プラットフォームは位置情報や移動を監視しているため、Super Changeは現実的な場所を選び、1日を通じた自然な移動をシミュレートします。
  3. センサーのシミュレーション - 実際のスマートフォンは持ち上げられたり傾けられたりします。まったく動かないデバイスは目立つため、センサーの動きをシミュレートします。
  4. 公式のアプリインストール元 - アプリは公式ストアからインストールされたように扱われるため、エラーや機能制限が減り、すべてのデバイスでGmailにサインインする必要もありません。
  5. ADBの隠蔽 - 自動化には操作用のチャネルが必要ですが、そのチャネルは隠されたままです。
  6. カスタムROM、Android 15、OTAアップデート - 専用に構築されたROMで、デバイスを返送しなくてもリモートで更新できます。

アカウントがまとめてBANされる理由

アカウントは1つのアイデンティティです。プロキシは、そのアイデンティティの自宅の住所です。

20個のアカウントが1つのアドレスを共有していると、プラットフォームからは、20人が同じ家に住み、同じ時間に起きて寝て、同じような種類のコンテンツに「いいね」しているように見えます。そのため、アカウントは1つずつではなく、まとめてBANされるのです。

GenRouterは、各スマートフォンに専用のアドレスを持たせるために存在します。Isolate Modeはさらにもう1つの役割を果たします。プロキシが切断された場合、スマートフォンが実際のアドレスを露出させる前に、そのスマートフォンのネットワークを直ちに遮断します。

プロキシ1→アカウント1

手順

  1. GenFarmerのコントロールパネルでOTGセクションを開く

  2. 2つのアドレス範囲を追加する

アプリごとに専用のデバイスIDを設定し、リセットや交換の後もアカウントデータを保持します。

Changeは、アプリケーションごとにデバイスに新しいアイデンティティを与えます。BackupとRestoreはアプリのアカウントデータを保持するため、再度ログインする必要がありません。その背景にある技術については、Change / SuperChangeとはで説明しています。

GenFarmerでのChange Device・Back Up・Restore

Change device

この機能を使うと、各アプリケーションから見えるデバイス情報を変更できます。実際には、同じスマートフォンで2つのTelegramアプリを動かし、それぞれのアプリに別のデバイスとして認識させることができます。

  1. デバイスを選択してChange deviceを開く

    デバイスを選択し、サイドメニューのChange deviceをクリックします。デフォルトのアイデンティティはSamsung Galaxy S21 Ultra 5Gです。

  2. パラメーターをランダムに生成するか、手動で設定する

    Random（ランダム）をクリックすると、システムがすべてのパラメーターをランダムに設定します。自分で設定する場合は、右上のManual（手動）にチェックを入れ、自由に調整してください。

  3. 確定する

    Changeをクリックします。新しい設定を適用するため、デバイスの接続が切れ、短時間再起動します。

  4. 確認する

    Device Info HWアプリを開いて新しいアイデンティティを確認します。変更後、デバイスはRealme RMX2030などと表示される場合があります。このアプリはAPKPureから無料でダウンロードできます。

Backup：SNSアカウントのデータ

  1. バックアップしたいアカウントを開く

    プラットフォームを開いてアカウントのプロフィールを表示し、すべてが正常な状態であることを確認します。

  2. アプリをバックアップする

    アプリを閉じ、アプリ（例：TikTok）にマウスを合わせてBackup Appを選択します。

Restore：SNSアカウントのデータ

  1. Restore Appを選ぶ

    バックアップファイルを保存したら、アプリに戻ってRestore Appを選択します。

  2. バックアップファイルを選ぶ

    先ほど保存したファイルを選択します。

  3. アプリを再度開く

    Restore successfulと表示されたら、アプリを閉じて再度開き、引き続きご利用ください。

BackupとRestoreがあれば、デバイスの交換も簡単です。アカウントを別のデバイスに移したりデバイスをリセットしたりする際に、再ログインや認証を経ずにリストアするだけで済みます。

Inspector

Inspectorは、アプリケーションからパッケージや要素の情報を取得し、自動化コードを書く際に利用するためのツールです。GenFarmerアプリとは別のウィンドウで開きます。

Inspectorのツールバー

  • Select Devices：現在GenFarmerに接続されているすべてのデバイスを一覧表示するドロップダウン
  • Reload：デバイスの現在の画面を再読み込みする
  • Enable Grid：要素のグリッドを表示し、要素を正確に特定する
  • Enable Swipe：Inspectorの画面上で直接スマートフォンをスワイプする
  • Enable Crop：画像をキャプチャしてBase64に変換し、Image searchノードで使用する

Inspectorの表示内容

デバイスの画面にマウスを合わせると、要素のブロックが表示されます。要素をクリックすると、中央の列にその要素とアプリケーションに関する情報が表示されます。

  • Mouse Pos：選択した位置の座標
  • Click：要素をクリックし、デバイスの画面を自動的に再読み込みする
  • Element Rect：要素の座標
  • Index：要素の優先順位
  • Text：要素に含まれるテキスト
  • Resourceid：要素のID
  • Package：アプリケーションのパッケージID
  • Description：要素の説明

アプリケーションのコード表示から要素を選択することもできます。

対処：Not valid device

アプリがライセンスエラーでデバイスを受け付けない場合です。原因は2つあり、そのうち1つは単に時計がずれているだけです。

GenFarmerアプリで発生する、無効なデバイスのエラーです。症状：アプリがデバイスを受け付けず、ライセンスエラーが表示されます。

発生する理由

  • 同じGenFarmerアカウントで複数のコンピューターに同時にサインインしている
  • あるコンピューターでサインインした後、別のコンピューターでサインインした
  • コンピューターの日付、時刻、またはタイムゾーンが実際の時刻と一致していない

GenFarmerアカウントは、1つのメールアドレスにつき、同時に1台のコンピューターでのサインインにのみ対応しています。

対処方法

  1. すべての場所からサインアウトする

    すべてのコンピューターでGenFarmerアカウントからサインアウトします。

  2. 時計を確認する

    日付、時刻、タイムゾーンがお住まいの地域の実際の時刻と一致しているか確認します。一致していない場合は、Date and Time Settings（日付と時刻の設定）を開いてSync now（今すぐ同期）をクリックし、タイムゾーンを再度確認してください。時計が既に正しかった場合は、手順3に進みます。

  3. 1台のコンピューターだけでサインインする

    それでもライセンスエラーが表示される場合は、コントロールパネルに表示されているすべてのデバイスを選択して削除し、アプリケーションを閉じてから再度開きます。

他の場所でサインインしたことがない場合でも、手順2は必ず行ってください。時計のずれだけでもこのエラーが発生します。それでも解決しない場合は、サポートに問い合わせてください。

対処：デバイスが表示されない（Unauthorized）

ADBがunauthorizedと報告するため、一部のスマートフォンが画面に表示されない場合です。お使いのボックスモデル用のADBキーファイルで解決します。

ボックス内の一部のスマートフォンが画面に表示されない主な原因です。デバイスは接続されているものの、ADBがunauthorized（未承認）と報告するため、GenFarmerがそれらを使用できません。

対処方法

  1. コマンドプロンプトを開く

    Windows + Rを押し、cmdと入力してEnterを押します。

  2. デバイスのステータスを確認する

    adb devicesと入力します。unauthorizedと表示されたデバイスはすべて、この問題が発生しています。

  3. サポートにADB Keyファイルを依頼する

    キーはお持ちのBoxphoneのモデルによって異なるため、GenFarmerサポートに連絡して正しいファイルを入手してください。送るべき情報については、サポートに問い合わせる前にをご覧ください。

  4. キーを正しいフォルダーに置く

    Cドライブ → Users → お使いのコンピューター名 → .androidを開きます。

  5. 既存のキーを置き換える

    GenFarmerから受け取ったADB Keyファイルをそのフォルダーにコピーし、確認が表示されたらReplace（置き換え）を選択します。

  6. ADBサーバーを再起動する

    コマンドプロンプトに戻り、下記の2つのコマンドを実行します。すべてのデバイスのステータスがdeviceと表示されれば、問題は解決しています。

adb kill-server
adb devices

adb devicesで何も認識されない場合は、まだコンピューターにADBがインストールされていません。まずADB環境をセットアップしてください。ADBコマンドと、動作要件と安全上の注意の要件をご覧ください。

対処：Boxphoneのインジケーターランプの異常

赤または点滅するランプは、1枚のメインボードのハードウェア故障です。スロットとボードのどちらに原因があるかを見分ける方法を説明します。

症状：インジケーターランプが点滅する、または赤く表示され、デバイスがソフトウェアから切断されます。

正常なランプの表示は、USBモードでは青、OTGモードでは緑です。赤や点滅は、そのメインボードのハードウェア故障であり、ソフトウェアの問題ではありません。

対処方法

  1. メインボードを別のスロットに差し替える

    異常のあるメインボードを取り外し、他のメインボードと位置を入れ替えます。これにより、故障がスロットとメインボードのどちらについて回るかがわかります。

  2. FPCケーブルを挿し直す

    入れ替えても問題が解決しない場合は、FPCケーブル（メインボードに沿って走る長いオレンジ色のリボンケーブル）を調整するか、挿し直してください。

FPCケーブルを挿し直すには、ボックスを開ける必要があります。自信がない場合は、まずサポートに問い合わせてください。動作要件と安全上の注意に記載のとおり、指示なく改変されたハードウェアは保証の対象外となります。

GenFarmerの標準的なリファレンス構成は、操作用PC 1台、ミニPC 1台、スイッチ1台、ボックス10台のクラスターです。多数のボックスを運用する段階になったら、安定性のため、またミニPCの負荷を分散するために、スイッチの使用をおすすめします。

  • GenRouter用にモデムの空きポートが1つ
  • 通信を安定させるためのLANケーブル：Cat5またはCat6（Cat6推奨）
  • 操作用コンピューターにWi-Fiは不要です。H3000とミニPCのどちらでも、LANで同じように動作します
  • 最低帯域幅：最初のボックスで約100 Mbps、以降1ボックスごとに約100 Mbps追加が目安です。TikTokが最も帯域を使うプラットフォームなので、この数値を基準に計画してください。1本のインターネット回線につき最大5ボックスまでにしてください。

実際には、ボトルネックになるのは自宅の回線ではなくプロキシです。回線の測定値に問題がないのにファームの動作がもたつく場合は、帯域を増やす前にまずプロキシを疑ってください。

ミニPCを使っていてWi-Fiが必要な場合

ミニPCはLANでのみ接続し、Wi-Fiを発信できません。そのため、USB接続のBoxphoneや通常のスマートフォンには別のデバイスが必要です。Aruba、Cisco、TP-Linkなどのアクセスポイントをアクセスポイントモードに設定して使用してください。こうすればアクセスポイントは電波の発信だけを行い、制御とIPの割り当てはルーターが引き続き担います。接続数に対応できるモデルを販売店にお問い合わせください。

3. システムの他の部分との接続方法

使用機器接続方法
GenRouter H3000まず電源を入れます。ルーターが緑色に点灯します。モデムをWANに、PCをLANに接続します。PCにLANポートがない場合は、代わりにGENROUTER-2.4GHzまたはGENROUTER-5GHzネットワークに接続します。次に192.168.5.1:9000を開き、ダッシュボードが表示されれば接続完了です。
LANケーブルなしのGenRouter H3000V3では、ルーターが別のWi-Fiネットワークを受信して再発信できます。GENROUTER-2.4GHzまたはGENROUTER-5GHzに接続し、再発信するネットワークを選んでパスワードを入力し、送信します。
ミニPCまず電源を入れます。モデムをETH0に、PCをETH1/ETH2/ETH3に、ボックスを残りのポートに接続し、192.168.5.1:9000を開きます。
LANによるボックス間の接続LANポートを備えたBoxphoneは、互いに数珠つなぎに接続してOTGモードで運用できます。デバイスが検出されない場合は、まずUSBで接続して認識させてから、OTGに戻してください。
使用機器操作用コンピューターの接続方法
GenRouter H3000PCにWi-Fiがある場合は、Wi-Fiで接続します。ない場合はLANを使用します：H3000のLANポートからPCのEthernet、またはBoxphoneのLANからPCのEthernet（この場合、H3000のLANポートをBoxphoneのLAN1またはLAN2に接続し、残りのLANポートをPCにつなぎます。P30ボックスに適用されます）。
ミニPCLANで接続します。Wi-Fiは使用できません。ノートパソコンにEthernetポートがない場合は、USB-LANまたはType-C-LANアダプターを用意してください。

テクニカルサポートから指示がない限り、ルーターの物理的なリセットボタンは絶対に押さないでください。また、指示なくコンピューター上でipconfigを実行したり、デバイスのIPを手動で変更したりしないでください。どちらも、正常に動いている構成を一瞬で失う原因になります。

ルーターは部屋の中央、またはできるだけデバイスの近くに置いてください。2.4GHzは遠くまで届きますが速度は遅く、5GHzは高速ですが届く範囲が短くなります。充電器やケーブルを交換する場合は、Type-Cケーブル付きのAndroidスマートフォン用充電器を使用してください。ルーターはケーブルとの相性に敏感で、新しいケーブルで動かないときに古いスマートフォンのケーブルなら動くこともよくあります。

配線が済んだら、ソフトウェア側の設定はUSBで接続するまたはOTG（LAN）で接続するをご覧ください。

4. プロキシの準備

アカウントは1つのアイデンティティです。プロキシは、そのアイデンティティの自宅の住所です。20個のアカウントが1つのアドレスを共有していると、プラットフォームからは、20人が同じ家に住み、同じ時間に起きて寝て、同じような種類のコンテンツに「いいね」しているように見えます。そのため、アカウントは1つずつではなく、まとめてBANされるのです。

ここから次のことが言えます。

  • スマートフォン1台につきプロキシを1つ。スマートフォン20台のボックス1つには20個のプロキシが必要です
  • お試しであれば、5つのアカウントを2〜3個のプロキシで運用しても構いませんが、これは本番運用の構成ではありません
  • Isolate Modeは安全装置です。プロキシが切断された、期限切れになった、またはエラーが発生した場合、そのスマートフォンは実際のアドレスに切り替わるのではなく、直ちにインターネットから遮断されます
  • GenRouterは、プロキシの割り当てに加えて、WebRTC、DNS、MACアドレス、位置情報、タイムゾーンも隠し、tracerouteをブロックし、LANスキャンを防ぎます

初日から何かを押し上げることはなく、スパムも行いません。一連の流れはすべて、実際の人間の行動に合わせたタイミングで進みます。

アルゴリズムが実際に測定しているもの

TikTok、Instagram、Facebookのリーチは、同じ5つのシグナルで決まります。パッケージがこのような設計になっているのはそのためです。

シグナルあなたにとっての意味
視聴時間と視聴維持率最も重要なシグナルです。視聴者が手を止めたか、最後まで見たか、繰り返し見たか、途中で離脱したか
初期のエンゲージメント「いいね」、シェア、コメント、保存は、投稿後すぐに発生する必要があります。一度にまとめて発生すると不自然に見えて抑制されますが、自然に分散していればデータが均等に流れ込みます
誰がエンゲージしているか数だけでなく、コンテンツに合った人かどうかが重要です。誤ったオーディエンスはアルゴリズムに誤った学習をさせ、配信が的外れな人に届いてしまいます
アカウントの履歴質の低いエンゲージメントを実行したアカウントを回復させるのは非常に困難です。激しく運用するより、正しく始めることの方が重要です
フォロワー以外の反応プラットフォームが見ているのは、フォロワーの反応ではなく、新しい人が反応するかどうかです。フォロワー以外の関心を引く投稿は、小さなアカウントからでも急速に拡散します

Boost - チャンネルの運用

  • 文脈に沿ったAI返信。AIが自分の動画に寄せられたコメントを読み、トピックとトーンに合った返信の下書きを作成します。表現は毎回異なります。

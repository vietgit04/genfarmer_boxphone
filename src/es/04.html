Change / Backup / Restore

Dale a cada app su propia identidad de dispositivo y conserva datos de cuenta que sobreviven a un reinicio o a un cambio de dispositivo.

Change le da a un dispositivo una nueva identidad para cada aplicación. Backup y Restore conservan los datos de cuenta de una app para que no tengas que volver a iniciar sesión. La tecnología detrás se explica en ¿Qué es Change / SuperChange?.

Change Device - Back Up - Restore en GenFarmer

Change device

Esta función te permite modificar la información del dispositivo que ve cada aplicación. En la práctica, puedes tener dos apps de Telegram en el mismo teléfono y que cada una vea un dispositivo diferente.

  1. Selecciona el dispositivo y abre Change device

    Selecciona el dispositivo y luego haz clic en Change device en el menú lateral. La identidad predeterminada es Samsung Galaxy S21 Ultra 5G.

  2. Genera los parámetros al azar o configúralos a mano

    Haz clic en Random (Aleatorio) para que el sistema genere al azar todos los parámetros. Para configurarlos tú mismo, marca Manual en la esquina superior derecha y ajústalos a tu gusto.

  3. Confirma

    Haz clic en Change. El dispositivo se desconecta y se reinicia brevemente para aplicar la nueva configuración.

  4. Verifica

    Abre la app Device Info HW para comprobar la nueva identidad: después del cambio, el dispositivo puede aparecer como Realme RMX2030. La app se descarga gratis desde APKPure.

Backup: datos de cuentas de redes sociales

  1. Abre la cuenta que quieres respaldar

    Ve a la plataforma, abre el perfil de la cuenta y comprueba que todo esté como debe.

  2. Haz la copia de seguridad de la app

    Cierra la app, pasa el cursor sobre ella (TikTok, por ejemplo) y selecciona Backup App (copia de seguridad de la app).

Restore: datos de cuentas de redes sociales

  1. Elige Restore App

    Con el archivo de copia de seguridad guardado, vuelve a la app y selecciona Restore App (restaurar la app).

  2. Elige el archivo de copia de seguridad

    Elige el archivo que guardaste antes.

  3. Vuelve a abrir la app

    Cuando veas Restore successful, cierra la app y ábrela de nuevo para seguir usándola.

Backup y Restore son lo que hace que un cambio sea sencillo: cuando pasas una cuenta a otro dispositivo o reinicias uno, restauras en lugar de volver a iniciar sesión y pasar por la verificación.

Control Center

La pantalla que usas todos los días: la barra lateral, la vista de transmisión, el control sincronizado y el Inspector.

Control Center es donde pasas la mayor parte del tiempo: la cuadrícula de teléfonos, la barra de herramientas que ajusta cómo se muestran, la vista de transmisión de un solo dispositivo, el control sincronizado y el Inspector para quien escribe scripts.

Menú de la barra lateral

La barra de herramientas a la izquierda del panel de control reúne las funciones para gestionar los dispositivos y ajustar cómo se ven en pantalla.

Ajustar la calidad de los dispositivos

  • Big Screen: el tamaño de la ventana de transmisión de un dispositivo. Mínimo 40%, máximo 100%
  • Small Screen: el tamaño de los mosaicos de dispositivos dentro de Control Devices: Thumbnail, Medium, Large o Extra Large
  • Big Quality: la calidad de imagen de la transmisión: Low, Medium, High o Extra (Extra ofrece la mejor experiencia)
  • Small Quality: la calidad de imagen de los mosaicos en la pantalla general: Low, Medium, High o Extra

Gestión de dispositivos

  • Select all: selecciona todos los dispositivos para instalar APK, detener tareas, etc.
  • Select device: selecciona dispositivos individuales para trabajar con ellos

Para quitar la selección de un dispositivo mientras Select all está activo, mantén pulsado Ctrl y haz clic en él.

Stream Device

Stream Device muestra la pantalla de un teléfono al tamaño real del dispositivo y transmite cada acción con fluidez.

  • Vol+ / Vol-: sube y baja el volumen
  • Screenshot: captura la pantalla del dispositivo
  • Power: apaga la pantalla
  • Rotate: gira la pantalla
  • Install APK: instala una aplicación directamente desde la transmisión
  • ADB Command: ejecuta comandos ADB adicionales
  • Reboot: reinicia el dispositivo
  • Switch Keyboard Method: abre los ajustes del teclado
  • Accessibility Settings: abre la interfaz de ajustes
  • Language: abre los ajustes de idioma
  • Connection Setting: abre los ajustes de conexión, como Wi-Fi y Bluetooth
  • Apps: muestra las aplicaciones instaladas en el dispositivo

Group Control

Group Control sincroniza los dispositivos: trabajas en un dispositivo y los demás repiten las mismas acciones.

Selecciona los dispositivos que quieres sincronizar.

Luego abre la transmisión de cualquiera de ellos para convertirlo en el dispositivo principal.

Trabaja en ese dispositivo y los demás lo seguirán de forma idéntica.

Group Control es gratuito y no tiene límite de acciones. La versión paso a paso, junto con la instalación de una app en todos los teléfonos, está en Control sincronizado e instalación de APK.

Inspector

Inspector obtiene información de paquetes y elementos de una aplicación, para usarla al escribir código de automatización. Se abre en una ventana aparte de la app GenFarmer.

Barra de herramientas del Inspector

  • Select Devices: el menú desplegable con todos los dispositivos conectados actualmente a GenFarmer
  • Reload: vuelve a cargar la pantalla actual del dispositivo
  • Enable Grid: muestra la cuadrícula de elementos para identificarlos con precisión
  • Enable Swipe: desliza en el teléfono directamente desde la pantalla del Inspector
  • Enable Crop: captura una imagen y la convierte a Base64 para el nodo Image search

Qué muestra la vista del Inspector

Pasa el ratón sobre la interfaz del dispositivo para mostrar los bloques de elementos. Haz clic en un elemento y la columna central se llenará con información sobre ese elemento y la aplicación.

La columna derecha de la vista de transmisión muestra:

  • Activity: la acción del elemento
  • XPathLite: el XPath que se usa en los scripts
  • ClassName: el nombre de clase del elemento
  • Mouse Pos: las coordenadas de la posición seleccionada
  • Click: hace clic en el elemento y vuelve a cargar la pantalla del dispositivo automáticamente
  • Element Rect: las coordenadas del elemento
  • Index: el orden de prioridad del elemento
  • Text: el texto que contiene el elemento
  • Resourceid: el ID del elemento
  • Package: el ID de paquete de la aplicación
  • Description: la descripción del elemento

También puedes seleccionar elementos desde la vista de código de la aplicación.

Account Manager

La hoja de cuentas dentro de la app: importar cuentas, asignar dispositivos y elegir qué cuenta ejecuta qué script.

Account Manager guarda tu hoja de cuentas dentro de la app GenFarmer, así que ya no necesitas Excel ni Google Sheets. En el plan la usas por primera vez el Día 2, y a partir del Día 3 también es donde eliges qué cuenta ejecuta qué script.

Agregar cuentas

Add Accounts te permite agregar cuentas a mano.

  • Please Input: el UID o nombre de usuario de la cuenta
  • Select Format: una plantilla predefinida por tipo de cuenta, o una personalizada
  • Custom Format: elige tú mismo los campos: UID, Password, Email, 2FA, etc.

Importar y exportar

  • Export: exporta el archivo de cuentas en formato XLSX
  • Import: importa un archivo CSV o XLSX. GenFarmer incluye un archivo de plantilla para trabajar a partir de él

Las columnas

  • Device: el dispositivo predeterminado de esa cuenta
  • Status: el estado de la cuenta
  • UID: el nombre de usuario
  • Email: el correo vinculado a la cuenta
  • Password: la contraseña
  • Email Password: la contraseña del correo, que se usa para leer los códigos de verificación
  • 2FA: el código de autenticación

Una vez agregada, la cuenta se ejecuta en el dispositivo que seleccionaste, mediante el Module o la App que uses.

Asignar un dispositivo a una cuenta es el paso que la gente se salta. Copia el Device ID de la pantalla principal en la columna Device ID; de lo contrario, el script no tiene ningún teléfono en el que ejecutarse.

App Manager

La biblioteca de aplicaciones que envías a los dispositivos, desde un archivo APK o desde la Store integrada en la app.

App Manager es la biblioteca de aplicaciones que puedes enviar a los dispositivos.

  • Name: el nombre de las aplicaciones instaladas
  • Android Version: la configuración mínima y la de destino
  • Size: el tamaño del archivo APK
  • Create At: cuándo se agregó el archivo a GenFarmer
  • Remove: elimina el archivo APK de GenFarmer
  • LoadAPK: sube un archivo APK a GenFarmer
Cómo cambiar de app con GenFarmer: instalar apps mediante APK o desde la Store

Instalar desde la Store

Además de los archivos APK, puedes instalar desde la Store, que ofrece aplicaciones que GenFarmer ha comprobado en cuanto a seguridad y compatibilidad con la mayoría de los dispositivos.

Descargar y luego seleccionar la versión: ese es todo el proceso.

Elige la versión que coincida con la versión de Android del dispositivo, o la instalación dará errores. Los pasos del lado del dispositivo están en Control sincronizado e instalación de APK.

Automatización

Apps, Modules, Tasks y Runs: cómo se crea un script, se guarda, se asigna a dispositivos y se le hace seguimiento.

La automatización es la forma en que el trabajo repetitivo pasa de tus manos a la máquina, mientras las funciones Antidetect mantienen vivas las cuentas. Sea lo que sea que ejecutes, hay un script para ello: escrito por ti, importado o comprado.

El día en que empiezas a usarla en el plan es el Día 3, y allí se describen los paquetes listos para usar (Auto Login, Trust, Boost).

My Apps

  1. My App: las automatizaciones de la cuenta: escritas por ti, importadas o compradas en la tienda
  2. Subscription: las automatizaciones compradas en la tienda, activas y vencidas
  3. Import App: instala una automatización desde un archivo genfarmer. Compra en la tienda o en otra fuente de confianza para evitar perder información
  4. Create App: crea y escribe un script nuevo
  • Select Devices: el dispositivo en el que quieres hacer pruebas
  • Select Node: los nodos que hacen posible crear scripts sin código
  • View Edit: muestra el script y los nodos que usa
  • Top Bar: las barras de herramientas de apoyo
  • Custom View: una imagen de portada personalizada para la app
  • Device View: el dispositivo que se va a transmitir
  • Table Column: diseña la tabla de datos con la información que necesita el script
  • Save: guarda la app y sus nodos
  • Run: prueba la app en el dispositivo seleccionado
  • Otras funciones: registros de ejecución, guardar con otro nombre, modo de depuración

My Modules

Un Module es una forma más avanzada de App, capaz de contener varias funciones más pequeñas dentro de un solo Module. La interfaz y las funciones son las mismas que en las Apps, con nodos adicionales para ejecutar varias Apps dentro del Module.

Lo que distingue a un Module es el nodo Context Menu, que divide las funciones y gestiona varias Apps dentro de un solo Module.

Saved Tasks

Saved Tasks guarda las tareas que ya creaste, para que volver a ejecutarlas cueste un solo clic.

  • Name: el nombre de la tarea
  • App: la app de script que usa la tarea
  • Devices: cuántos dispositivos se ejecutan en la tarea
  • Runs: cuántas veces se ha ejecutado
  • Last run started at / Last run status / Last run duration: la ejecución más reciente

Para crear una tarea, entra en un módulo o una app y elige Create Task.

Ponle nombre a la tarea y luego elige los dispositivos en los que debe ejecutarse.

Cuando termines, puedes guardarla y ejecutarla de inmediato, o guardarla para más tarde.

Runs

Runs es donde se gestionan varias tareas al mismo tiempo.

  • App: el nombre de tu app de script
  • Task: el nombre de la tarea
  • Result: la cantidad de ejecuciones
  • Started at / Finished at / Duration: cuándo se ejecutó y durante cuánto tiempo
  • Status: Running, Done o Aborted
  • Run: vuelve a ejecutar la tarea

Las tareas se crean en Saved Tasks y aparecen aquí una vez que están en ejecución.

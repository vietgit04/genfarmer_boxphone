2. ネットワークに必要な条件

運用規模デバイスポートの使い方スイッチ
1ボックス - スマートフォン20台GenRouter H3000モデムからのLANケーブルをWANポートに接続し、PCをLANポートに接続するか、GENROUTER-2.4GHz / GENROUTER-5GHzのWi-Fiに接続します不要
2〜4ボックス - スマートフォン40〜80台ミニPCモデムをETH0に、PCをETH1、ETH2、ETH3のいずれかに、ボックスを残りのポートに接続しますポートが足りなくなった場合のみ
最大10ボックス - スマートフォン200台ミニPC + スイッチモデムをETH0に接続し、それ以外はすべてスイッチ経由で接続します必要。安定動作が確認されている構成はPC 1台 + ミニPC 1台 + スイッチ1台 + ボックス10台です
10ボックス超2つ目のクラスター上記のクラスター構成を繰り返します必要（クラスターごとに1台）

GenFarmerの標準的なリファレンス構成は、操作用PC 1台、ミニPC 1台、スイッチ1台、ボックス10台のクラスターです。多数のボックスを運用する段階になったら、安定性のため、またミニPCの負荷を分散するために、スイッチの使用をおすすめします。

  • GenRouter用にモデムの空きポートが1つ
  • 通信を安定させるためのLANケーブル：Cat5またはCat6（Cat6推奨）
  • 操作用コンピューターにWi-Fiは不要です。H3000とミニPCのどちらでも、LANで同じように動作します
  • 最低帯域幅：最初のボックスで約100 Mbps、以降1ボックスごとに約100 Mbps追加が目安です。TikTokが最も帯域を使うプラットフォームなので、この数値を基準に計画してください。1本のインターネット回線につき最大5ボックスまでにしてください。

実際には、ボトルネックになるのは自宅の回線ではなくプロキシです。回線の測定値に問題がないのにファームの動作がもたつく場合は、帯域を増やす前にまずプロキシを疑ってください。

ミニPCを使っていてWi-Fiが必要な場合

ミニPCはLANでのみ接続し、Wi-Fiを発信できません。そのため、USB接続のBoxphoneや通常のスマートフォンには別のデバイスが必要です。Aruba、Cisco、TP-Linkなどのアクセスポイントをアクセスポイントモードに設定して使用してください。こうすればアクセスポイントは電波の発信だけを行い、制御とIPの割り当てはルーターが引き続き担います。接続数に対応できるモデルを販売店にお問い合わせください。

3. システムの他の部分との接続方法

使用機器接続方法
GenRouter H3000まず電源を入れます。ルーターが緑色に点灯します。モデムをWANに、PCをLANに接続します。PCにLANポートがない場合は、代わりにGENROUTER-2.4GHzまたはGENROUTER-5GHzネットワークに接続します。次に192.168.5.1:9000を開き、ダッシュボードが表示されれば接続完了です。
LANケーブルなしのGenRouter H3000V3では、ルーターが別のWi-Fiネットワークを受信して再発信できます。GENROUTER-2.4GHzまたはGENROUTER-5GHzに接続し、再発信するネットワークを選んでパスワードを入力し、送信します。
ミニPCまず電源を入れます。モデムをETH0に、PCをETH1/ETH2/ETH3に、ボックスを残りのポートに接続し、192.168.5.1:9000を開きます。
LANによるボックス間の接続LANポートを備えたBoxphoneは、互いに数珠つなぎに接続してOTGモードで運用できます。デバイスが検出されない場合は、まずUSBで接続して認識させてから、OTGに戻してください。
使用機器操作用コンピューターの接続方法
GenRouter H3000PCにWi-Fiがある場合は、Wi-Fiで接続します。ない場合はLANを使用します：H3000のLANポートからPCのEthernet、またはBoxphoneのLANからPCのEthernet（この場合、H3000のLANポートをBoxphoneのLAN1またはLAN2に接続し、残りのLANポートをPCにつなぎます。P30ボックスに適用されます）。
ミニPCLANで接続します。Wi-Fiは使用できません。ノートパソコンにEthernetポートがない場合は、USB-LANまたはType-C-LANアダプターを用意してください。

テクニカルサポートから指示がない限り、ルーターの物理的なリセットボタンは絶対に押さないでください。また、指示なくコンピューター上でipconfigを実行したり、デバイスのIPを手動で変更したりしないでください。どちらも、正常に動いている構成を一瞬で失う原因になります。

ルーターは部屋の中央、またはできるだけデバイスの近くに置いてください。2.4GHzは遠くまで届きますが速度は遅く、5GHzは高速ですが届く範囲が短くなります。充電器やケーブルを交換する場合は、Type-Cケーブル付きのAndroidスマートフォン用充電器を使用してください。ルーターはケーブルとの相性に敏感で、新しいケーブルで動かないときに古いスマートフォンのケーブルなら動くこともよくあります。

配線が済んだら、ソフトウェア側の設定はUSBで接続するまたはOTG（LAN）で接続するをご覧ください。

4. プロキシの準備

アカウントは1つのアイデンティティです。プロキシは、そのアイデンティティの自宅の住所です。20個のアカウントが1つのアドレスを共有していると、プラットフォームからは、20人が同じ家に住み、同じ時間に起きて寝て、同じような種類のコンテンツに「いいね」しているように見えます。そのため、アカウントは1つずつではなく、まとめてBANされるのです。

ここから次のことが言えます。

  • スマートフォン1台につきプロキシを1つ。スマートフォン20台のボックス1つには20個のプロキシが必要です
  • お試しであれば、5つのアカウントを2〜3個のプロキシで運用しても構いませんが、これは本番運用の構成ではありません
  • Isolate Modeは安全装置です。プロキシが切断された、期限切れになった、またはエラーが発生した場合、そのスマートフォンは実際のアドレスに切り替わるのではなく、直ちにインターネットから遮断されます
  • GenRouterは、プロキシの割り当てに加えて、WebRTC、DNS、MACアドレス、位置情報、タイムゾーンも隠し、tracerouteをブロックし、LANスキャンを防ぎます

ルーターが対応しているプロキシ

種類形式と備考
SOCKS5socks5://user:pass@ip:port
HTTP / HTTPS対応しています。手順は同じです
PPPoEマルチセッション回線からプロキシを作成します。ベトナムのみ対応。プロキシの数は回線のセッション数と同じで、IPは実際のISPから割り当てられます
DPNGenRouter独自のネットワークです。10か国のレジデンシャルプロキシを利用でき、その国の共有在庫が十分にあれば別の国にローテーションすることもできます

プロキシの追加

  1. まず、メモ帳や文書に1行に1つのプロキシの形式でリストを準備します
  2. 192.168.5.1:9000を開き、Proxy Managerに移動してAdd proxyをクリックします
  3. リストに合った形式を選び、貼り付けてAdd proxyをクリックします
  4. 割り当てるには：Devices → Update proxyを開いてプロトコルを選び、詳細を入力する（Input Manually）か、保存済みのものを選択します（Select from List）
  5. ボックス全体を一度に設定するには、デバイス表の上部にあるチェックボックスにチェックを入れてUpdate Proxyをクリックし、リストを貼り付けます。ルーターが各デバイスに異なるプロキシを割り当てます

購入に関するアドバイス（どのプロバイダーを選ぶか、レジデンシャルとデータセンターのどちらにするか、ローテーションプロキシがファームで安全かどうか）は、まだ確定していない唯一の部分です。推測せずにサポートにお問い合わせください。ベトナムにお住まいの場合は、マルチセッションのPPPoEを利用すれば、プロキシを購入する必要がないかもしれません。

自動化パッケージ

パッケージとは何か、どんな種類があるか、その中の3つのツールと守るべき実行順序について説明します。

パッケージは、1つのプラットフォーム向けの既製の自動化スクリプトのセットです。アプリ内のStoreで購入すると、以降はAutomation → My Appsに配置され、他のアプリと同じように実行できます。まだ購入されていない場合は、WhatsApp（+84 97 123 46 01）でGenFarmerの営業担当に連絡するか、ユーザーコミュニティでお問い合わせください。ここで説明する作業はすべて手動でも行えますが、はるかに時間がかかります。

アンチディテクトブラウザではなくスマートフォンファームを使う理由

SNSや音楽のプラットフォームは、もはやアンチディテクトブラウザでは運用できなくなっています。ブラウザはパターンが漏れやすく、すぐにチェックポイントがかかり、エンゲージメントが抑制されます。また、ブラウザでは実際の再生としてカウントされる視聴環境を作れません。パッケージは、実際のIPを持つ実機で動かすことを前提に作られています。

すべてのパッケージに共通する4つのステップ

アカウントをウォームアップ → オーディエンスを設定 → エンゲージメントを発生 → 配信を後押し

初日から何かを押し上げることはなく、スパムも行いません。一連の流れはすべて、実際の人間の行動に合わせたタイミングで進みます。

アルゴリズムが実際に測定しているもの

TikTok、Instagram、Facebookのリーチは、同じ5つのシグナルで決まります。パッケージがこのような設計になっているのはそのためです。

シグナルあなたにとっての意味
視聴時間と視聴維持率最も重要なシグナルです。視聴者が手を止めたか、最後まで見たか、繰り返し見たか、途中で離脱したか
初期のエンゲージメント「いいね」、シェア、コメント、保存は、投稿後すぐに発生する必要があります。一度にまとめて発生すると不自然に見えて抑制されますが、自然に分散していればデータが均等に流れ込みます
誰がエンゲージしているか数だけでなく、コンテンツに合った人かどうかが重要です。誤ったオーディエンスはアルゴリズムに誤った学習をさせ、配信が的外れな人に届いてしまいます
アカウントの履歴質の低いエンゲージメントを実行したアカウントを回復させるのは非常に困難です。激しく運用するより、正しく始めることの方が重要です
フォロワー以外の反応プラットフォームが見ているのは、フォロワーの反応ではなく、新しい人が反応するかどうかです。フォロワー以外の関心を引く投稿は、小さなアカウントからでも急速に拡散します

人間らしく見せるための仕組み

  • ランダム化されたタスク：操作のタイミングと種類（視聴、「いいね」、保存、スクロール）は、決まったパターンを繰り返すのではなく、実行ごとに変わります
  • 上限と休憩：スクリプトには上限、一時停止、バックグラウンドでの動作（視聴、スクロール、スキップ）が組み込まれており、プラットフォームはこれを自然な動きとして認識します
  • プラットフォームごとの設計：各パッケージは、そのプラットフォームのコンテンツ配信の仕組みと、あなたの市場のユーザーの行動に合わせて設計されています

最初のパッケージを実行する前に

  • お試し用の5つのアカウントが、認証を求められることなく48時間の放置期間を乗り越えていること。2日目をご覧ください
  • すべてのスマートフォンに専用のプロキシがあり、Isolate Modeが有効になっていること。ルーターとプロキシをご覧ください
  • ユーザーマニュアルのリンクではなく公式APKフォルダーから、すべてのスマートフォンにプラットフォームのアプリがインストールされていること。2日目 · 手順3をご覧ください
  • パッケージが自動でコメントする場合は、vilao.aiのAPIキーを用意していること。これは0日目で準備すべき項目でした。途中でキーがないことに気づくと、途中で止まらざるを得なくなります

TikTokパッケージ

TikTok向けのTrustとBoost：パッケージの内容、運用の目安となる数値、注意すべき点を説明します。

パッケージの内容

TikTokには両方のツールが揃っています。Trustは実際の活動履歴を持つアカウントを育て、使い捨てのアカウントとして扱われないようにします。Boostは、お持ちのアカウント全体で投稿・配信の運用を行います。

Trust - アカウントの育成

  • 業界のキーワードで育成。システムがターゲットのキーワードに関連する動画を探し、実際の人間のように閲覧します。これにより、アカウントがそのキーワードでおすすめに表示されるようになり、信頼できるアカウントに見える履歴が築かれます。
  • AIによる自動投稿と自動コメント。投稿はスケジュールに沿って実行され、コメントはコピーではなく生成されるため、多数のアカウントが同じ文面を書き込むことはありません。
  • 多数のアカウントを一括管理。数百のアカウントを1つの画面で一元的に同期・監視でき、技術的なスキルは必要ありません。
  • ランダムフォロー。システムがおすすめリストからランダムに選んでフォローするため、繰り返しの動作に見えることはありません。

Boost - チャンネルの運用

  • 文脈に沿ったAI返信。AIが自分の動画に寄せられたコメントを読み、トピックとトーンに合った返信の下書きを作成します。表現は毎回異なります。
  • 大規模なスケジュール設定と公開。アカウントリスト全体で動画を一括アップロード・スケジュール設定し、市場ごとに適切な時間に公開します。公開タイミングをずらすため、チャンネルが同じように投稿することはありません。
  • ログインごとに数値が散らばるのではなく、チャンネル別のレポートを備えた全アカウント共通の1つの画面で管理できます。

すべて実機で動作するため、アップロードはブラウザではなく、ネイティブなモバイル環境で行われます。

リンクに紐づく情報を1〜2週間ごとに変更する理由。毎日変更すると誰も管理しきれず、何か月も放置すると同じリンクのリストに何度も繰り返しアクセスすることになります。これこそ、プラットフォームが一斉に取り締まるパターンです。

TikTok特有の注意点

  • TikTokは最も帯域を使うプラットフォームです。1ボックスあたり100 Mbpsという数値は、TikTokを基準にしています。
  • ユーザーマニュアルに記載されたAPKリンクのうち、正しいのはTikTokのものだけですが、それでも2日目 · 手順3の公式フォルダーの方が安全な入手元です。
  • 自動コメントにはvilao.aiのAPIキーが必要です。必要になった日ではなく、0日目のうちに取得してください。

ユーザーマニュアルのTikTokの章はp. 17-50の34ページで、マニュアルの中で最も充実した章です。

停止すべきサイン

  1. アカウントが普段より頻繁に認証を求められる。
  2. 投稿の再生数が突然まったくなくなる。
  3. 稼働中のスマートフォンの台数が、はっきりした理由もなく減り続ける。

一晩でBANされたアカウントがある場合は、規模を拡大しないでください。まずプロキシと実行速度を確認し直してください。

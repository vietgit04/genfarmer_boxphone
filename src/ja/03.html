今日の問い：どんな成果を生み出せますか？

この2日間は、新しい概念を学ぶためではなく、操作に習熟するための期間です。

自分のプラットフォームの章を読む → コンテンツのジャンルに合わせて設定 → テスト用スクリプトを実行 → 停止すべきサインを覚える

手順

  1. 自分のプラットフォームの章を読む

    設定のセクションを中心に読んでください。

  2. 実際のコンテンツのジャンルに合わせて設定する

    トピックを間違えると、アカウントは別のことに興味を持つ人としてウォームアップされ、投稿が適切なユーザーに届かなくなります。

    運用するパッケージの推奨設定：自動化パッケージ →

  3. 1つのスクリプトを最初から最後まで実行する

    結果はご自身で確認してください。

  4. 停止すべき3つのサインを見分けられるようになる

    1. アカウントが普段より頻繁に認証を求められる。
    2. 投稿の再生数が突然まったくなくなる。
    3. 稼働中のスマートフォンの台数が、はっきりした理由もなく減り続ける。

完了の目安

ドキュメントを再び開かなくても、新しいスクリプトを自分で設定できること。

ここからはウォームアップ期間に入り、2〜4週間続きます。この間、数値はゆっくりとしか伸びませんが、それは正常です。遅れを取り戻そうとして速度を上げないでください。

問題が起きたときは：症状別トラブルシューティング

動作要件と安全上の注意

最初のボックスを接続する前に、コンピューター、電源、ケーブルが満たすべき条件と、保証が無効になる2つのルールを説明します。

このページの内容は、すべて何かを接続する前に確認すべきことです。購入すべきもののチェックリストは0日目にあります。このページでは、そのチェックリストの背景にあるハードウェアと安全面の詳細を説明します。

PCの最低構成（操作用コンピューター）

  • オペレーティングシステム：Windows 10 64ビット
  • GPU：専用GPUが必要です。最低NVIDIA GeForce GTX 1050

GenFarmerはWindows向けに作られており、Windows 10で最もよく動作します。最もスムーズにお使いいただくには、このバージョンをご使用ください。

電源

Boxphoneのモデル対応電圧
Box P30100V - 240V
Box P30+180V - 240V

運用するBoxphoneの台数に見合った容量を持つ、安定した電源を使用してください。これにより、デバイスの誤動作の原因となる過負荷や電圧低下を防げます。

安全上のルール

Boxphoneのデバイス設定で、開発者モードやUSBデバッグは絶対に有効にしないでください。画面が永久に消えてデバイスが使用できなくなるおそれがあります。

技術チームの指示なく、Boxphoneのハードウェアを改造したり手を加えたりしないでください。ハードウェアやソフトウェアが改変された製品は、保証および返品ポリシーの対象外となります。

ネットワークとアイデンティティ

ルーターを最大のパフォーマンスで設定する方法

多数のアカウントを安全に運用するには、プロキシまたはVPNが不可欠です。推奨される構成は、デバイスごとに別々のIPアドレスを使うことです。GenFarmerは、まさにこの目的のためにH3000ルーターとMiniPCを販売しています。このルールの理由は2日目で説明しています。

ケーブル

  • GenFarmerのケーブルを使用しない場合は、Ugreenなど信頼できるブランドのUSBケーブルを選んでください
  • LANには、通信を安定させるためCat-6ケーブルを使用してください

ADB環境

WindowsでADBをセットアップする方法

WindowsにADB環境をセットアップすると、Boxphoneを操作したり、問題を自分で診断したりできるようになります。また、Unauthorized deviceの対処にも必要になるため、必要になる前にセットアップしておく価値があります。ADBコマンドをご覧ください。

USBでBoxphoneを接続する

1ボックスとGenRouter H3000を使う場合です。4つの手順と、現在のモードを示すランプについて説明します。

1ボックス + GenRouter H3000の場合はこのモードを使用します。H3000が扱えるのは1ボックスのみです。2ボックス以上の場合は、ミニPCとOTGモードが必要です。

動画ガイド：USBでBoxphoneを接続する

ポートとLEDランプのガイド

手順

  1. Boxphoneを電源に接続する

  2. Boxphoneの電源を入れる

    電源ボタンを1回押してBoxphoneの電源を入れます。ファンが回り始め、青色のランプが点灯すれば、デバイスはUSBモードです。

    ランプが緑色の場合は、電源ボタンを2回押してモードを切り替えてください。

  3. USBケーブルを接続する

    BoxphoneからUSBケーブルを操作用コンピューターに接続します。

  4. GenFarmerアプリを開く

    GenFarmerアプリケーションを起動して、システムの使用を開始します。

ランプの表示パターンは覚えておく価値があります：青 = USBモード、緑 = OTGモード、赤または点滅 = メインボードの問題（対処法を見る）。

OTG（LAN）でBoxphoneを接続する

ミニPCを使う場合のモードで、2ボックス以上で使える唯一のモードです。ハードウェアとソフトウェアの両方の手順を1つのリストにまとめています。

OTGはOn-The-Goの略で、デバイスをLAN経由でPCに直接接続する方式です。ミニPCを使う場合の標準モードであり、2ボックス以上で使える唯一のモードです。

動画ガイド：GenFarmerでOTGをセットアップする方法

始める前に

  • PCとBoxphoneは同じモデムまたはWi-Fiルーターに接続されている必要があります
  • コンピューターまたはルーターにUSBケーブルとLANケーブルの両方を接続してください
GenFarmerでOTGをセットアップする方法

手順

  1. GenFarmerのコントロールパネルでOTGセクションを開く

  2. 2つのアドレス範囲を追加する

    192.168.4.1-255と192.168.5.1-255を追加し、ソフトウェアがデバイスを探す場所を指定します。

  3. デバイスを選択してActivateをクリックする

    OTGに切り替えたいデバイスをすべて選択し、Activateをクリックします。

  4. Boxphoneの電源ボタンを2回押す

    デバイスの接続が切れてポートが解放されたら、すぐにBoxphoneの電源ボタンを2回押してOTGモードに切り替えます。

  5. すべてのランプが緑になるまで待つ

    すべてのランプが緑であれば、すべてのメインボードがOTGモードになっています。

  6. Scanをクリックする

    GenFarmerソフトウェアに戻り、Scanをクリックしてデバイスを検出します。

OTGモードでは、ミニPCを経由してスマートフォンが既にインターネットに接続されているため、スマートフォンでWi-Fiを設定する必要はありません。

Scanでスマートフォンが見つからない - ほとんどの場合、2つのアドレス範囲の両方が追加されていないか、追加したもののActivateをクリックしていないことが原因です。何よりも先にこの2点を確認してください。

OTGは接続されているのに、スマートフォンがまだインターネットに接続できない場合。次の順番で確認してください：まずプロキシ、プロキシに問題がなければスマートフォンの時刻です。PCの時刻に合わせて修正してください。

同期操作とAPKのインストール

1台の操作、20台の同時操作、そして全台へのアプリのインストールについて説明します。

日々の運用に欠かせないスキルです。1台の操作、20台の同時操作、そして全台へのアプリのインストールを説明します。

動画ガイド：デバイスを個別および同期して操作する、APKをインストールする

デバイスを個別および同期して操作する、APKをインストールする

個別操作

操作したいデバイスをダブルクリックし、直接操作します。

同期操作

Select All Devicesをクリックするか、Ctrl + Aを押すか、ドラッグして複数のデバイスを選択します。次に、そのうちいずれか1台をダブルクリックして操作すると、選択されている他のすべてのデバイスが同じ操作を繰り返します。

Select allがオンの状態で特定のデバイスを除外するには、Ctrlを押しながらそのデバイスをクリックします。

APKのインストール

  1. APKファイルを入手する

    APKPureやAPKComboなどの配布元からダウンロードします。ロードマップで使うプラットフォームのアプリについては、ユーザーマニュアルに記載されたリンクではなく、2日目に記載したGenFarmerの公式フォルダーを使用してください。

  2. デバイスを選択してInstall APKを選ぶ

    すべてのデバイス、またはインストールしたいデバイスだけを選択して右クリックし、Install APKを選びます。

  3. ファイルを選んでインストールする

    コンピューター上のAPKファイルを選択し、Installをクリックします。

  4. 緑色の表示を待つ

    インストールにかかる時間はアプリのサイズによって異なります。完了するとインジケーターが緑色になります。

アプリのバージョンはデバイスのAndroidバージョンに合わせてください。合っていないと、インストールに失敗したり、起動時にアプリがクラッシュしたりします。GenFarmer内で利用できるバージョンはApp Managerに一覧表示されています。

ADBコマンド

任意の機能です。GenFarmer内から複数のデバイスにコマンドを実行する方法と、Unauthorizedエラーの対処に必要なADB環境のセットアップについて説明します。

任意の機能で、コマンドラインの操作に慣れている方にのみ役立ちます。このページを読み飛ばしてもロードマップには何の影響もありません。ただし、Unauthorized deviceの対処には、PCにADBがインストールされている必要があります。

GenFarmerでADBコマンドを使う方法

コマンドの実行

ツールバーでADB Commandを選択します。

入力欄にコマンドを貼り付け、Execute（実行）をクリックします。

ChatGPTやGeminiなどのAIツールにコマンドを書いてもらうこともできます。たとえば、全台でChromeを開きたい場合は、「AndroidデバイスでGoogle Chromeを開くADBコマンド」と依頼し、その結果を入力欄に貼り付けて実行します。

セットアップ

Change / Backup / Restore

アプリごとに専用のデバイスIDを設定し、リセットや交換の後もアカウントデータを保持します。

Changeは、アプリケーションごとにデバイスに新しいアイデンティティを与えます。BackupとRestoreはアプリのアカウントデータを保持するため、再度ログインする必要がありません。その背景にある技術については、Change / SuperChangeとはで説明しています。

GenFarmerでのChange Device・Back Up・Restore

Change device

この機能を使うと、各アプリケーションから見えるデバイス情報を変更できます。実際には、同じスマートフォンで2つのTelegramアプリを動かし、それぞれのアプリに別のデバイスとして認識させることができます。

  1. デバイスを選択してChange deviceを開く

    デバイスを選択し、サイドメニューのChange deviceをクリックします。デフォルトのアイデンティティはSamsung Galaxy S21 Ultra 5Gです。

  2. パラメーターをランダムに生成するか、手動で設定する

    Random（ランダム）をクリックすると、システムがすべてのパラメーターをランダムに設定します。自分で設定する場合は、右上のManual（手動）にチェックを入れ、自由に調整してください。

  3. 確定する

    Changeをクリックします。新しい設定を適用するため、デバイスの接続が切れ、短時間再起動します。

  4. 確認する

    Device Info HWアプリを開いて新しいアイデンティティを確認します。変更後、デバイスはRealme RMX2030などと表示される場合があります。このアプリはAPKPureから無料でダウンロードできます。

Backup：SNSアカウントのデータ

  1. バックアップしたいアカウントを開く

    プラットフォームを開いてアカウントのプロフィールを表示し、すべてが正常な状態であることを確認します。

  2. アプリをバックアップする

    アプリを閉じ、アプリ（例：TikTok）にマウスを合わせてBackup Appを選択します。

Restore：SNSアカウントのデータ

  1. Restore Appを選ぶ

    バックアップファイルを保存したら、アプリに戻ってRestore Appを選択します。

  2. バックアップファイルを選ぶ

    先ほど保存したファイルを選択します。

  3. アプリを再度開く

    Restore successfulと表示されたら、アプリを閉じて再度開き、引き続きご利用ください。

BackupとRestoreがあれば、デバイスの交換も簡単です。アカウントを別のデバイスに移したりデバイスをリセットしたりする際に、再ログインや認証を経ずにリストアするだけで済みます。

ソフトウェア

Control Center

毎日使う画面です。サイドバー、ストリーム表示、同期操作、Inspectorについて説明します。

Control Centerは、最も多くの時間を過ごす画面です。スマートフォンのグリッド、表示方法を調整するツールバー、1台のデバイスのストリーム表示、同期操作、そしてスクリプトを書く方向けのInspectorがあります。

サイドバーメニュー

コントロールパネルの左側にあるツールバーには、デバイスを管理し、画面上の表示を調整するための機能がまとめられています。

デバイスの表示品質の調整

  • Big Screen：デバイスのストリームウィンドウのサイズ。最小40%、最大100%
  • Small Screen：Control Devices内のデバイスタイルのサイズ。Thumbnail、Medium、Large、Extra Large
  • Big Quality：ストリームの画質。Low、Medium、High、Extra（Extraが最も快適です）
  • Small Quality：一覧画面のタイルの画質。Low、Medium、High、Extra

デバイスの管理

  • Select all：APKのインストールやタスクの停止などのため、すべてのデバイスを選択します
  • Select device：作業対象のデバイスを個別に選択します

Select allが有効な状態で特定のデバイスの選択を解除するには、Ctrlを押しながらそのデバイスをクリックします。

Stream Device

Stream Deviceは、スマートフォンの画面を実際のデバイスと同じサイズで表示し、すべての操作をスムーズにストリーミングします。

  • Vol+ / Vol-：音量を上げる・下げる
  • Screenshot：デバイスの画面をキャプチャする
  • Power：画面をオフにする
  • Rotate：画面を回転する
  • Install APK：ストリームから直接アプリケーションをインストールする
  • ADB Command：追加のADBコマンドを実行する
  • Reboot：デバイスを再起動する
  • Switch Keyboard Method：キーボードの設定を開く
  • Accessibility Settings：設定画面を開く
  • Language：言語の設定を開く
  • Connection Setting：Wi-FiやBluetoothなどの接続設定を開く
  • Apps：デバイスにインストールされているアプリケーションを表示する

Group Control

Group Controlはデバイスを同期させる機能です。1台のデバイスで操作すると、残りのデバイスが同じ操作を繰り返します。

同期させたいデバイスを選択します。

次に、そのうちいずれか1台のストリームを開き、メインのデバイスにします。

そのデバイスで操作すると、他のデバイスもまったく同じように動作します。

Group Controlは無料で、操作回数の制限もありません。全スマートフォンへのアプリのインストールも含めた手順は、同期操作とAPKのインストールに掲載しています。

Inspector

Inspectorは、アプリケーションからパッケージや要素の情報を取得し、自動化コードを書く際に利用するためのツールです。GenFarmerアプリとは別のウィンドウで開きます。

Inspectorのツールバー

  • Select Devices：現在GenFarmerに接続されているすべてのデバイスを一覧表示するドロップダウン
  • Reload：デバイスの現在の画面を再読み込みする
  • Enable Grid：要素のグリッドを表示し、要素を正確に特定する
  • Enable Swipe：Inspectorの画面上で直接スマートフォンをスワイプする
  • Enable Crop：画像をキャプチャしてBase64に変換し、Image searchノードで使用する

Inspectorの表示内容

デバイスの画面にマウスを合わせると、要素のブロックが表示されます。要素をクリックすると、中央の列にその要素とアプリケーションに関する情報が表示されます。

ストリーム表示の右側の列には、次の情報が表示されます。

  • Activity：要素のアクション
  • XPathLite：スクリプト作成に使うXPath
  • ClassName：要素のクラス名
  • Mouse Pos：選択した位置の座標
  • Click：要素をクリックし、デバイスの画面を自動的に再読み込みする
  • Element Rect：要素の座標
  • Index：要素の優先順位
  • Text：要素に含まれるテキスト
  • Resourceid：要素のID
  • Package：アプリケーションのパッケージID
  • Description：要素の説明

アプリケーションのコード表示から要素を選択することもできます。

Account Manager

アプリ内のアカウントシートです。アカウントのインポート、デバイスの割り当て、どのアカウントでどのスクリプトを実行するかの選択を行います。

Account ManagerはアカウントシートをGenFarmerアプリ内で管理するため、ExcelやGoogle Sheetsは不要になります。ロードマップでは2日目に初めて使用し、3日目からは、どのアカウントでどのスクリプトを実行するかを選ぶ場所にもなります。

アカウントの追加

Add Accountsでは、アカウントを手動で追加できます。

  • Please Input：アカウントのUIDまたはユーザー名
  • Select Format：アカウントの種類ごとに用意されたテンプレート、またはカスタムのテンプレート
  • Custom Format：UID、Password、Email、2FAなどの項目を自分で選択します

インポートとエクスポート

  • Export：アカウントファイルをXLSX形式でエクスポートします
  • Import：CSVまたはXLSXファイルをインポートします。GenFarmerには作業用のテンプレートファイルが付属しています

各列の説明

  • Device：そのアカウントのデフォルトのデバイス
  • Status：アカウントのステータス
  • UID：ユーザー名
  • Email：アカウントに紐づいたメールアドレス
  • Password：パスワード
  • Email Password：メールのパスワード。認証コードの読み取りに使用します
  • 2FA：認証コード

アカウントを追加すると、使用するModuleまたはAppを通じて、選択したデバイス上でそのアカウントが実行されます。

アカウントへのデバイスの割り当ては、見落とされがちな手順です。メイン画面からDevice IDをDevice ID列にコピーしてください。そうしないと、スクリプトを実行するスマートフォンがありません。

Devices（デバイス）

アカウントで使用できるデバイス、有効なデバイス、残りの枠数を確認します。

Devices画面では、アカウントに紐づいたデバイスを管理します。

デバイスの概要

  • Total：アカウントで使用できるデバイスの数
  • Active：現在使用中のデバイス
  • Free Slot：あと何台追加できるか

AssignedとUnassigned

  • Assigned：有効化済みで使用可能なデバイス
  • Unassigned：有効化待ちのデバイス。対象のデバイスでActiveをクリックすると、ステータスがAssignedに変わります

ここでデバイスが有効にならない場合、原因はたいてい対処：Not valid deviceで説明している2つのライセンス問題のいずれかです。

App Manager

APKファイルまたはアプリ内Storeから、デバイスに配信するアプリケーションのライブラリです。

App Managerは、デバイスに配信できるアプリケーションのライブラリです。

  • Name：インストールされているアプリケーションの名前
  • Android Version：最小構成と対象構成
  • Size：APKファイルのサイズ
  • Create At：ファイルがGenFarmerに追加された日時
  • Remove：GenFarmerからAPKファイルを削除する
  • LoadAPK：GenFarmerにAPKファイルをアップロードする
GenFarmerでアプリを変更する方法：APKまたはStoreからアプリをインストールする

Storeからのインストール

APKファイルのほかに、Storeからもインストールできます。Storeには、GenFarmerが安全性とほとんどのデバイスとの互換性を確認したアプリケーションが揃っています。

流れはダウンロードしてから、バージョンを選択するだけです。

デバイスのAndroidバージョンに合ったバージョンを選んでください。合っていないとインストール時にエラーが発生します。デバイス側の手順は同期操作とAPKのインストールに掲載しています。

Automation（自動化）

Apps、Modules、Tasks、Runs：スクリプトの作成、保存、デバイスへの割り当て、追跡の方法を説明します。

Automationは、繰り返しの作業を人の手から機械に移す仕組みで、Antidetect機能によってアカウントを守ります。何を実行するにしても、そのためのスクリプトがあります。自分で書いたもの、インポートしたもの、購入したもののいずれかです。

ロードマップでこの機能を使い始めるのは3日目で、既製のパッケージ（Auto Login、Trust、Boost）についてもそこで説明しています。

My Apps

  1. My App：アカウントに属する自動化。自分で書いたもの、インポートしたもの、ストアで購入したもの
  2. Subscription：ストアで購入した自動化（有効なものと期限切れのもの）
  3. Import App：genfarmerファイルから自動化をインストールします。情報の流出を避けるため、ストアまたは信頼できる別の入手元から購入してください
  4. Create App：新しいスクリプトを作成して書きます
  • Select Devices：テストに使うデバイス
  • Select Node：ノーコードでのスクリプト作成を可能にするノード
  • View Edit：スクリプトとその中で使われているノードを表示します
  • Top Bar：補助用のツールバー
  • Custom View：アプリのカスタムカバー画像
  • Device View：ストリーム表示するデバイス
  • Table Column：スクリプトに必要な情報のためのデータテーブルを設計します
  • Save：アプリとそのノードを保存します
  • Run：選択したデバイスでアプリをテストします
  • その他の機能：実行ログ、名前を付けて保存、デバッグモード

My Modules

Moduleは、Appをさらに発展させた形式で、1つのModuleの中に複数の小さな機能をまとめることができます。画面と機能はAppsと同じですが、Module内で複数のAppsを実行するためのノードが追加されています。

Moduleの特徴はContext Menuノードで、機能を分割し、1つのModule内で複数のAppsを管理します。

Saved Tasks

Saved Tasksには作成済みのタスクが保存されており、ワンクリックで再実行できます。

  • Name：タスクの名前
  • App：タスクが使用するスクリプトアプリ
  • Devices：タスクで実行されるデバイスの数
  • Runs：実行された回数
  • Last run started at / Last run status / Last run duration：直近の実行

タスクを作成するには、モジュールまたはアプリを開いてCreate Taskを選択します。

タスクに名前を付け、実行するデバイスを選択します。

完了したら、保存してすぐに実行するか、後で使うために保存しておくことができます。

Runs

Runsでは、複数のタスクを同時に管理します。

  • App：スクリプトアプリの名前
  • Task：タスクの名前
  • Result：実行回数
  • Started at / Finished at / Duration：実行日時と所要時間
  • Status：Running、Done、Aborted
  • Run：タスクを再実行します

タスクはSaved Tasksで作成し、実行中になるとここに表示されます。

Settings（設定）

言語、保存場所、デバッグモードなどの自動化に関するスイッチを設定します。

Settingsには、ソフトウェアの基本的な設定がまとめられています。

General

言語と、ライトモードまたはダークモードを選択します。

Storage

  • Clear Cache：キャッシュデータを削除し、ストレージを初期状態に戻します

  • Copy Profiles to Selected Path：選択したパスにファイルをコピーします
  • Move Profiles to Selected Path：選択したパスにファイルを移動します

Automation

  • Enable Debug Mode：デバッグを有効にします
  • Tracking Node When Running：モジュールの実行中にノードを記録します
  • Sync Profiles Data After Running Task：タスクの終了後にプロファイルデータを同期します

API

開発者向け：同じマシン上の別のプログラムからApps、Tasks、Runsを操作するためのRESTfulエンドポイントです。

GenFarmerは、Automation Apps、Tasks、Runsを管理するためのRESTfulエンドポイントを公開しており、同じマシン上の別のプログラムから自動化を操作できます。このページは開発者向けで、1週間のロードマップでは必要ありません。

ベースURL

http://127.0.0.1:55554/

Automation API

機能メソッドエンドポイント
アプリの一覧を取得GET/automation/apps
アプリの詳細を取得GET/automation/apps/:id
アプリを更新PUT/automation/apps
アプリを削除DELETE/automation/apps
 
curl -X GET 'http://127.0.0.1:55554/automation/apps?userId=3&page=1&limit=25&order=desc&orderBy=updatedAt'

curl -X GET 'http://127.0.0.1:55554/automation/apps/adoFNVNN6Jwl8FlbZCfni'

curl -X PUT 'http://127.0.0.1:55554/automation/apps' \
  -H 'Content-Type: application/json' \
  -d '{"id":"adoFNVNN6Jwl8FlbZCfni","userId":3,"name":"New App","description":"","version":"1.0.0","script":{"flow":{"nodes":[],"edges":[]}}}'

curl -X DELETE 'http://127.0.0.1:55554/automation/apps' \
  -H 'Content-Type: application/json' \
  -d '{"ids": ["2ykTiCbEOAYC_5_tR5Wp-"]}'

Task API

機能メソッドエンドポイント
タスクを作成POST/automation/tasks
タスクの一覧を取得GET/automation/runs
タスクを更新PUT/automation/tasks/:id
タスクにデバイスを割り当てPUT/automation/tasks/:id/add-devices
タスクからデバイスを削除PUT/automation/tasks/:id/remove-devices
タスクを削除DELETE/automation/tasks
 
curl -X POST 'http://127.0.0.1:55554/automation/tasks' \
  -H 'Content-Type: application/json' \
  -d '{"appId":"adoFNVNN6Jwl8FlbZCfni","input":[],"userId":3,"name":"test","devices":{"enable":true,"list":[]}}'

curl -X PUT 'http://127.0.0.1:55554/automation/tasks/uNDVKT_VwhEDuXT3PGUUv/add-devices' \
  -H 'Content-Type: application/json' \
  -d '{"devices":{"enabled":true,"list":[{"id":"emulator-5554","serialNo":"00f65a5d","name":"SM-G960N"}]}}'

curl -X DELETE 'http://127.0.0.1:55554/automation/tasks' \
  -H 'Content-Type: application/json' \
  -d '{"ids": ["uNDVKT_VwhEDuXT3PGUUv"]}'

  -H 'Content-Type: application/json' \
  -d '{"deviceIds":[]}'

curl -X GET 'http://127.0.0.1:55554/automation/runs/xhfjAeUOB5SXC8d5RiK_c/storages?page=1&limit=25'

対処：Not valid device

アプリがライセンスエラーでデバイスを受け付けない場合です。原因は2つあり、そのうち1つは単に時計がずれているだけです。

GenFarmerアプリで発生する、無効なデバイスのエラーです。症状：アプリがデバイスを受け付けず、ライセンスエラーが表示されます。

発生する理由

  • 同じGenFarmerアカウントで複数のコンピューターに同時にサインインしている
  • あるコンピューターでサインインした後、別のコンピューターでサインインした
  • コンピューターの日付、時刻、またはタイムゾーンが実際の時刻と一致していない

GenFarmerアカウントは、1つのメールアドレスにつき、同時に1台のコンピューターでのサインインにのみ対応しています。

対処方法

  1. すべての場所からサインアウトする

    すべてのコンピューターでGenFarmerアカウントからサインアウトします。

  2. 時計を確認する

    日付、時刻、タイムゾーンがお住まいの地域の実際の時刻と一致しているか確認します。一致していない場合は、Date and Time Settings（日付と時刻の設定）を開いてSync now（今すぐ同期）をクリックし、タイムゾーンを再度確認してください。時計が既に正しかった場合は、手順3に進みます。

  3. 1台のコンピューターだけでサインインする

    それでもライセンスエラーが表示される場合は、コントロールパネルに表示されているすべてのデバイスを選択して削除し、アプリケーションを閉じてから再度開きます。

他の場所でサインインしたことがない場合でも、手順2は必ず行ってください。時計のずれだけでもこのエラーが発生します。それでも解決しない場合は、サポートに問い合わせてください。

対処：デバイスが表示されない（Unauthorized）

ADBがunauthorizedと報告するため、一部のスマートフォンが画面に表示されない場合です。お使いのボックスモデル用のADBキーファイルで解決します。

ボックス内の一部のスマートフォンが画面に表示されない主な原因です。デバイスは接続されているものの、ADBがunauthorized（未承認）と報告するため、GenFarmerがそれらを使用できません。

対処方法

  1. コマンドプロンプトを開く

    Windows + Rを押し、cmdと入力してEnterを押します。

  2. デバイスのステータスを確認する

    adb devicesと入力します。unauthorizedと表示されたデバイスはすべて、この問題が発生しています。

  3. サポートにADB Keyファイルを依頼する

    キーはお持ちのBoxphoneのモデルによって異なるため、GenFarmerサポートに連絡して正しいファイルを入手してください。送るべき情報については、サポートに問い合わせる前にをご覧ください。

  4. キーを正しいフォルダーに置く

    Cドライブ → Users → お使いのコンピューター名 → .androidを開きます。

  5. 既存のキーを置き換える

    GenFarmerから受け取ったADB Keyファイルをそのフォルダーにコピーし、確認が表示されたらReplace（置き換え）を選択します。

  6. ADBサーバーを再起動する

    コマンドプロンプトに戻り、下記の2つのコマンドを実行します。すべてのデバイスのステータスがdeviceと表示されれば、問題は解決しています。

adb kill-server
adb devices

adb devicesで何も認識されない場合は、まだコンピューターにADBがインストールされていません。まずADB環境をセットアップしてください。ADBコマンドと、動作要件と安全上の注意の要件をご覧ください。

対処：Boxphoneのインジケーターランプの異常

赤または点滅するランプは、1枚のメインボードのハードウェア故障です。スロットとボードのどちらに原因があるかを見分ける方法を説明します。

症状：インジケーターランプが点滅する、または赤く表示され、デバイスがソフトウェアから切断されます。

正常なランプの表示は、USBモードでは青、OTGモードでは緑です。赤や点滅は、そのメインボードのハードウェア故障であり、ソフトウェアの問題ではありません。

対処方法

  1. メインボードを別のスロットに差し替える

    異常のあるメインボードを取り外し、他のメインボードと位置を入れ替えます。これにより、故障がスロットとメインボードのどちらについて回るかがわかります。

  2. FPCケーブルを挿し直す

    入れ替えても問題が解決しない場合は、FPCケーブル（メインボードに沿って走る長いオレンジ色のリボンケーブル）を調整するか、挿し直してください。

FPCケーブルを挿し直すには、ボックスを開ける必要があります。自信がない場合は、まずサポートに問い合わせてください。動作要件と安全上の注意に記載のとおり、指示なく改変されたハードウェアは保証の対象外となります。

ハードウェアとセットアップ

Boxphoneシステムを運用するには何が必要ですか？

  • ハードウェア：Boxphoneと、必要に応じてIPのセキュリティとネットワーク管理のためのルーター
  • ソフトウェア：自動化ツールとスクリプト
  • リソース：インターネット接続、SNSアカウント、そしてデバイスに異なるIPアドレスを与えるためのプロキシまたはVPN

PCの仕様や電圧を含む要件の一覧は、動作要件と安全上の注意に掲載しています。

Boxphoneの各デバイスに異なるIPアドレスを持たせるにはどうすればよいですか？

デバイスごとにプロキシまたはVPNを使用します。GenFarmerではGenRouterも販売しています。GenRouterはプロキシやVPNをすばやく割り当て、MAC、DNS、WebRTCなどのネットワークパラメーターを偽装し、LANスキャンをブロックします。これがアカウントの存続にとってなぜ重要かは2日目で、デバイスやプロキシの選び方についてはルーターとプロキシで説明しています。

1台のBoxphoneで何個のアカウントを運用できますか？

  • 最も安全なのは：1台のデバイスにつき、1プラットフォームあたり1アカウント
  • それ以上に増やすこともできますが、推奨される上限は1台のデバイスにつき、1プラットフォームあたり3アカウントです

まずBoxphoneをレンタルして試すことはできますか？

GenFarmerのCloudphoneサービスをレンタルして、システムを試すことができます。SNS用途にはCloudphone GenFarmer、ゲームや放置ゲーム用途にはGenplay.ioをご利用ください。

ボックスだけでなくエミュレーターでも動作しますか？

はい。GenFarmerは、スマートフォンファームとエミュレーターの両方に対応した画面ストリーミングとノーコード自動化のツールです。LDPlayerについては、チャンネルに解説動画があります：LDPlayerとGenFarmerを接続する方法 - エミュレーターでの自動化。

できること、できないこと

Boxphoneはゲームや放置ゲームに使えますか？

はい。特に、軽量なゲームや放置ゲーム、そして自動チェックイン、ペットの育成、ファーミングシステムなどの簡単な自動化に適しています。対応例としては、Roblox、Play Together、Clash of Clansなどがあります。Lien Quan、Ymir、Raven2などの重いゲームには、それに見合ったハードウェアを持つBoxphoneのモデルが必要です。

GenFarmerはBoxphoneで収益を得る方法を教えてくれますか？

いいえ。GenFarmerが提供しているのは、自社エコシステム内のデバイスとソフトウェアの使い方（操作、インストール、最適化、デバイス管理）に関するドキュメントです。これらのツールをご自身の業務に活用していただくためのものです。

ノーコード自動化はどこから学び始めればよいですか？

GenFarmerは、YouTubeチャンネル「GenFarmer Vietnam」で、初級から上級までのノーコード自動化の無料講座を公開しています。講座で使われている機能については、Automation（自動化）で説明しています。

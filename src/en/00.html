Getting Started

1-Week Course - Getting Started with GenFarmer BoxPhone

The one-week course plus the full setup and software guide, in one place. Version 1.1 · 09/2026.

Five days to master the system, not five days to see results. Results take 2-4 weeks of warming up accounts. These are two different milestones, and knowing that up front saves you disappointment.

Watch the video tutorial Contact support

How this documentation is organised. The one-week course teaches the order of things and the reason behind each one. Setup and Software hold the step-by-step procedures with screenshots, so the course can stay short and never repeat them. Reference is what you open once something is already wrong.

How the pieces fit together

The whole system in one picture: the box, the router, the control app and the automation package - what each one does, and in what order you put them together. Each piece is taught in full on its own page, listed in the table below.

Layer 1Boxphone20 phones per box
Layer 2RouterOne network route per phone
ThroughoutControl appControl and manage
Layer 4PackageRuns the work for you
Boxphone
Hardware · Usually 20 phones per box
  • 1 box + GenRouter H3000 goes in USB mode
  • Mini PC goes in OTG mode: add the two address ranges, click Active, then Scan
  • Done when Scan finds 20/20 phones and a phone responds when you toggle the flashlight
Router
GenRouter H3000 (1 box) · Mini PC (from 2 boxes)
  • Each phone gets its own internet route, nothing shared
  • Assign one proxy per phone
  • Isolate Mode: when a proxy dies, that phone's network is cut immediately
  • Control panel at 192.168.5.1:9000
Control app
GenFarmer software · Installed on the control computer · The hub of the system
  • Control Center: control all 20 phones, synchronized actions, install APKs
  • Account Manager: import the account sheet, assign Device IDs, choose which account runs which script
  • Store: download the automation package
Package
Ready-made scripts · TikTok, Facebook, Instagram, X, Spotify
  • Auto Login: log accounts in and out in bulk
  • Trust: warm up accounts, run for 2-4 weeks
  • Boost: push engagement, only after enough warming up
  • If you have not bought one yet, contact GenFarmer sales on WhatsApp +84 97 123 46 01

Where is layer 3? Account + Proxy has no box of its own in this picture because it does not sit at one place in the chain: the proxy is assigned in the router, and the account sheet lives in the control app. You do both on Day 2.

Conventions used in this documentation

  • HDSD p. N - the matching page number in the full User Manual (141 pages).
  • Done when - the criterion that tells you the day is complete. If you have not met it, stay on that day; do not move on.
  • Coming soon - a detailed guide for this part is still being written. If you need it right now, contact support using the ready-made template and you will be guided directly.

Steps

    Focus on the configuration section.

  2. Configure it for your actual content niche

    Pick the wrong topic and your accounts will be warmed up as people interested in something else, and your posts will not reach the right audience.

    Recommended settings for the package you are running: Automation packages →

  3. Run one complete script from start to finish

    Read the results yourself.

  4. Learn to recognize the three signs that mean stop

    2. Posts suddenly lose all their views.

Requirements and safety notes

What your computer, your power supply and your cables have to be before the first box is plugged in - plus the two rules that void the warranty.

Everything on this page comes before you plug anything in. The checklist of what to buy is on Day 0; this page is the hardware and safety detail behind that checklist.

Minimum PC configuration (controller computer)

  • Operating system: Windows 10, 64-bit
  • GPU: a dedicated GPU is required, minimum NVIDIA GeForce GTX 1050

GenFarmer is built for Windows and works best on Windows 10. Use that version for the smoothest experience.

Power supply

Boxphone modelSupported voltage
Box P30100V - 240V
Box P30+180V - 240V

Use a stable power source with enough capacity for the number of Boxphones you run. This prevents the overloads and voltage drops that make devices misbehave.

Safety rules

In the device settings of the Boxphone, never enable Developer Mode or USB Debugging. Doing so can turn the screen off permanently and leave the device unusable.

Do not modify or interfere with the hardware of the Boxphone without guidance from the technical team. Products with altered hardware or software fall outside the warranty and return policy.

Network and identity

How to set up your router for maximum performance

To run many accounts safely, a proxy or VPN is essential, and the recommended setup is a separate IP address for each device. GenFarmer sells the H3000 router and the MiniPC for exactly this. The reason behind the rule is on Day 2.

Cables

  • If you are not using GenFarmer cables, pick USB cables from a known brand such as Ugreen
  • For LAN, use Cat-6 cable to keep transmission stable

ADB environment

How to set up ADB on Windows

Setting up the ADB environment on Windows lets you control the Boxphone and diagnose problems yourself. It is also what the Unauthorized device fix depends on, so it is worth doing before you need it. See ADB commands.

Buttons, ports and lights

Every physical control on the box and the router, the light codes, and the buttons in the app that drive the same things.

One page for every physical control on the hardware and every button in the app that drives it. If you are looking for where do I press to do this, start here rather than reading a procedure end to end.

Port and LED light guide

On the Boxphone

The power button

What you doWhat happens
Press onceThe box turns on. The fans start and the light comes up
Press twiceThe box switches connection mode, between USB and OTG

That second press is the one people miss. In OTG mode you press it right after the devices disconnect to release the port, and in USB mode you press it if the light came up green when you wanted blue.

The indicator light

LightMeaningWhat to do
BlueThe box is in USB modeCarry on - this is what you want with a GenRouter H3000
GreenThe box is in OTG modeThis is what you want with a mini PC
Red, or flickeringA mainboard fault, and the device drops out of the softwareFix: indicator light error - swap the mainboard to another slot, then reseat the FPC cable

The ports

  • USB and LAN/OTG on the same box. You switch between them with that one button, and GenFarmer does not charge to change the port
  • Boxphones with a LAN port can be chained to each other and run in OTG - see Router & proxy
  • Cooling is 4 fans, and the box runs on a 550W Turbo power supply

In the device settings of the phones, never enable Developer Mode or USB Debugging. It can turn the screen off permanently and leave the device unusable, and hardware altered without guidance falls outside the warranty.

On the router

DeviceControls
GenRouter H3000Power it on and it lights up green. Modem into WAN, PC into LAN, or join the GENROUTER-2.4GHz / GENROUTER-5GHz network. The control panel is at 192.168.5.1:9000
Mini PCModem into ETH0, PC into ETH1, ETH2 or ETH3, boxes into whatever is left. Same control panel at 192.168.5.1:9000

Never press the physical reset button on the router unless technical support tells you to, and do not change the device IP on your computer by hand. Both are quick ways to lose a working setup.

Connect the Boxphone via USB

For 1 box with a GenRouter H3000. Four steps, and a light that tells you which mode you are in.

Use this mode when you have 1 box + a GenRouter H3000. The H3000 drives one box only; from two boxes up you need a mini PC and OTG mode.

Video guide: Connect the Boxphone via USB

Port and LED light guide

Steps

  1. Connect the Boxphone to the power supply

  2. Power on the Boxphone

    Press the power button once to turn the Boxphone on. The fan starts running and a blue light means the device is in USB mode.

    If the light is green, press the power button twice to switch modes.

  3. Connect the USB cable

    Connect the USB cable from the Boxphone to the controller computer.

  4. Open the GenFarmer app

    Launch the GenFarmer application to start using the system.

The light code is worth memorising: blue = USB mode, green = OTG mode, red or flickering = a mainboard problem (see the fix).

Setup

Connect the Boxphone via OTG (LAN)

For a mini PC, and the only workable mode from 2 boxes up. Both halves of the procedure, hardware and software, in one list.

OTG stands for On-The-Go: connecting the devices to the PC directly over the LAN. This is the default mode when you use a mini PC, and the only workable mode from 2 boxes up.

Video guide: How to set up OTG with GenFarmer

Before you start

  • The PC and the Boxphone must be on the same modem or Wi-Fi router
  • Plug in both the USB and the LAN cable to the computer or router
How to set up OTG with GenFarmer

Steps

  1. Open the OTG section in the GenFarmer control panel

  2. Add the two address ranges

    Add 192.168.4.1-255 and 192.168.5.1-255 so the software knows where to look for the devices.

  3. Select the devices and click Activate

    Select every device you want to switch to OTG, then click Activate.

  4. Press the power button twice on the Boxphone

    As soon as the devices disconnect to release the port, press the power button twice on the Boxphone to switch it into OTG mode.

  5. Wait until every light is green

    Green on all lights means every mainboard is in OTG mode.

  6. Click Scan

    Go back to the GenFarmer software and click Scan to detect the devices.

In OTG mode the phones already have internet access through the mini PC, so you do not need to set up Wi-Fi on them.

Scan finds no phones - almost always because the two address ranges were not both added, or they were added but Activate was never clicked. Check those two before anything else.

OTG is plugged in but a phone still has no internet. Check in this order: first the proxy, and if the proxy is fine, the time on the phone - correct it to match the time on your PC.

Synchronized control and APK installation

Driving one phone, driving twenty at once, and installing an app on all of them.

This is the day-to-day skill: driving one phone, driving twenty at once, and putting an app on all of them.

Video guide: Control devices individually and in sync, install APKs

Control devices individually and in sync, install APKs

Individual control

Double-click the device you want to control and operate it directly.

Synchronized control

Click Select All Devices, press Ctrl + A, or drag to select several devices. Then double-click any one of them to control it - every other selected device repeats the same actions.

To leave one device out while Select all is on, hold Ctrl and click that device.

Installing an APK

  1. Get the APK file

    Download it from a source such as APKPure or APKCombo. For the platform apps used in the roadmap, use the official GenFarmer folder listed in Day 2, not the links printed in the User Manual.

  2. Select the devices and choose Install APK

    Select all of them, or only the ones you want, right-click and choose Install APK.

  3. Pick the file and install

    Choose the APK file on your computer, then click Install.

  4. Wait for the green light

    Installation time depends on the size of the app. The indicator turns green when it has finished.

Match the app version to the Android version of the device, otherwise the install fails or the app crashes on launch. The versions available inside GenFarmer are listed in App Manager.

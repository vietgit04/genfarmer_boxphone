Fix: Only some phones are found

GenFarmer shows 18 or 19 phones out of 20, or Scan finds none. Check the mode first, then the light, then the slot.

You see this

"Only 19/20 phones show""Scan finds 0 devices""Device 4 is missing""Earlier it was 16, now 19"

Check in this order

  1. Mode and lights

    Use USB for 1 box + H3000 and OTG for a Mini PC or 2+ boxes. The light tells you the mode: blue = USB, green = OTG, red or flickering = mainboard fault.

    Fix: press the Boxphone power button twice to switch mode, as in Connect via OTG (LAN). A red light: go to step 5.

  2. OTG: both address ranges and Activate

    In the GenFarmer OTG section, add 192.168.4.1-255 and 192.168.5.1-255, select the devices, click Activate, wait until every light is green, then click Scan.

    Fix: if phones are not found in OTG, connect them by USB once so they are picked up, then switch back to OTG.

  3. Other software holding the phones

    Another phone-control program running at the same time can keep some phones away from GenFarmer.

    Fix: close every other phone-control program, restart the Boxphone, then open only GenFarmer.

  4. ADB status

    Press Windows + R, type cmd, then run adb devices.

    Fix: phones listed as unauthorized need the ADB key file for your box model - follow Fix: Device not showing (Unauthorized).

  5. Slot or mainboard

    A red or flickering light is hardware. Swap the mainboard into another slot: if the fault follows the mainboard, it is the mainboard; if it stays, it is the slot. Then reseat the FPC cable.

    Fix: see Fix: Boxphone indicator light error. If you are not comfortable opening the box, contact support first.

  6. Did it start after a factory reset or a PC format?

    A reset can remove the activation or the ADB setup. Developer Mode and USB Debugging are already enabled on GenFarmer phones - do not change these settings yourself.

    Fix: contact support to restore the ROM.

Contact support when

The light stays red after the slot and cable checks, ADB stays unauthorized, or phones are still missing in the correct mode after an OTG scan.

Fix: Automation stops or shows no results

The task stops early, finishes with 0 results, or says Success with nothing posted. Seven checks, most common cause first.

You see this

"The automation keeps stopping""0 results""It only runs for 1-3 minutes""It says Success but nothing was uploaded""GenFarmer crashes after a few hours"

Check in this order

  1. Are the platform app and the package installed?

    Open App Manager and check the platform app. Open the Store, check the correct package is downloaded, then check Automation → My Apps.

    Fix: install the missing app from the official APK folder (Day 2 · step 3); download the correct package from the Store.

  2. Is the account assigned to the right device?

    Open Account Manager: every account needs a Device ID and must be assigned to the device you run. In Automation, check the task's device list.

    Fix: copy the Device ID from the main screen into the Device ID column, select the right devices and run again.

  3. What does the run say?

    Open Automation → Runs and check Result, Status (Running / Done / Aborted), Started at, Finished at and Duration.

    Fix: Aborted - fix the missing setup and run again. Done but 0 results - go to step 4.

  4. Can the account and the phone get online?

    Log in to the account by hand. Each phone needs its own proxy with Isolate Mode on.

    Fix: replace a dead proxy (see Fix: No internet after assigning a proxy) and correct the phone time. Do not scale up if accounts ask for verification or get banned.

  5. Is the account warmed up?

    For TikTok, Facebook and Instagram, run Auto Login first, and Trust before Boost. Trust needs 2-4 weeks before real results.

    Fix: do not run Boost on a new account.

  6. Is it the right APK and package version?

    If a different app opens, or the script cannot find a button, the APK is probably wrong.

    Fix: remove it and reinstall from the official APK folder. For Store packages, delete and download the latest version.

  7. Are the computer and the connection OK?

    Windows 10 64-bit with a dedicated NVIDIA GTX 1050 or better. Phones must appear in GenFarmer in the right mode: USB for 1 box + H3000, OTG for a Mini PC.

    Fix: update GenFarmer to the latest version and restart it before testing again.

Special cases

Stops after about 12 minutes

Restart the device and run GenFarmer as administrator. Still stops: contact support with a screen recording.

Spotify stops after about 30 seconds or shows Aborted

Log out of Spotify and log in again. A stream must last over 30 seconds on a Premium account.

Only 19 of 20 phones run, or some are paused

Open Settings: turn off Devices Disconnect, check Device Threads and enter all 20 device IDs again. If the phones are not even found, see Fix: Only some phones are found.

Success but no post appears

Record the whole run - account, device, package and the final screen - and send it to support.

Contact support when

Package, account assignment, devices, proxies, app version and connection mode are all checked and the run still stops.

Fix: No internet after assigning a proxy

The proxy is added but the phone cannot get online. Check the proxy itself before anything else.

You see this

"Proxy configured but no internet""I added the proxy but it's not working""Proxy shows red""Instagram says no internet"

Check in this order

  1. Is the proxy alive and in the right format?

    Test it on checkproxy.vip and check it has not expired. SOCKS5 is socks5://user:pass@ip:port; HTTP/HTTPS uses the HTTP format.

    Fix: replace a dead or expired proxy. Put one proxy per line in Notepad before adding them.

  2. Is the protocol right?

    In the GenRouter panel (192.168.5.1:9000) open Proxy Manager → Add proxy and pick the format that matches your list.

    Fix: if HTTP does not work, try SOCKS5.

  3. Was it added in the right place?

    GenRouter or Mini PC: in the router panel. Cloudphone: on each device in GenFarmer, not on the router page.

    Fix: add it again in the right place.

  4. Is it assigned to the phone?

    Router panel → Devices → Update proxy → Input Manually or Select from List. One proxy per phone. For a whole box, tick the top checkbox, click Update Proxy and paste the list.

  5. Isolate Mode and the phone time

    Turn Isolate Mode on, then check the date, time and time zone on the phone.

    Fix: correct the time. With Isolate Mode on, a dead proxy cuts that phone's internet on purpose - that is what protects your accounts.

  6. Is the proxy too slow?

    Test the response time on checkproxy.vip.

    Fix: replace proxies with a very high ping.

  7. One phone or all phones?

    One phone: check that phone's proxy. A whole box: check the LAN cable and the modem port, then Scan again - see Fix: No internet on GenRouter or Mini PC.

Special cases

All proxies show Inactive

Test them on checkproxy.vip, note the error shown after Update Proxy and send it to support.

Content still comes from your real country

Match the phone time zone and language to the proxy country.

Contact support when

The proxy is live, correctly formatted and assigned, the time is right, and the phone still has no internet.

Send us

  • H3000 or Mini PC
  • Proxy format and protocol
  • The checkproxy.vip result
  • A screenshot of the router device list

Fix: Proxy is lost or the IP changes back

The proxy disappears after a restart, or the IP drifts back to your own country. Almost always the phone's random MAC address.

You see this

"After restarting the phone the proxy is gone""After a power cut all proxies are lost""After a few minutes the IP goes back to my country"Many red Offline devices in GenRouter

Check in this order

  1. Is the phone using a random MAC? (most common)

    Android changes its Wi-Fi MAC on every reconnect, and GenRouter assigns proxies by MAC - so after a restart the phone looks like a new device.

    Fix: on every phone open Settings → Wi-Fi → GENROUTER-2.4GHz → Privacy → Use device MAC, then assign the proxy again. Do this on all phones before you assign proxies.

  2. Old red Offline devices?

    They are old identities left by the random MAC. They do not affect anything and are removed automatically - use the filter to hide them.

  3. Does the IP go back after a few minutes?

    Check the proxy itself on a computer first: is it a rotating proxy, and is it still alive? Also check the protocol did not switch from SOCKS5 to HTTP after a reboot.

Contact support when

Every phone uses its device MAC, the proxy is live, and it is still lost.

Send us

  • A screenshot of the device list
  • The MAC of the affected phone
  • Proxy type: static or rotating, SOCKS5 or HTTP
  • What happened just before: a restart, a power cut, or nothing

Fix: No internet on GenRouter or Mini PC

No internet, DNS errors, or a connection that keeps dropping. Check that the device fits your setup, then the cables.

You see this

"No internet connection""Can't reach DNS server""Mini PC connection drops in and out""I can only open 192.168.5.1"Several phones show "Try again"

Check in this order

  1. The right device for your setup

    H3000 = 1 box, USB mode. Mini PC = 2 boxes or more, OTG mode + LAN. Do not run 2 boxes on an H3000.

  2. Wiring

    H3000: modem → WAN; computer → LAN, or Wi-Fi GENROUTER-2.4GHz / 5GHz. Mini PC: modem → ETH0; computer → ETH1, ETH2 or ETH3; boxes → the remaining ports. Use Cat6 cable.

    Fix: correct the ports, and replace a cable if the speed drops - one customer went from 94 Mbps back to full speed with a new cable.

  3. Can you open the panel?

    Open 192.168.5.1:9000. The Mini PC needs a LAN cable - it has no Wi-Fi.

    Fix: if it does not open, recheck the cable and the network. Do not press reset or change the computer IP by hand without support.

  4. Only some phones offline?

    Check their proxies first - see Fix: No internet after assigning a proxy. Isolate Mode cuts a phone whose proxy died.

  5. Phone time and Airplane Mode

    The time and time zone must match the computer, and Airplane Mode must be off.

  6. Whole box offline or unstable after adding boxes?

    Check the shared LAN cable and the modem port, then Scan. Plan at most 5 boxes per internet line and about 100 Mbps per box. Add a LAN switch if the Mini PC carries every box directly.

Special cases

The Mini PC gets no DHCP, no panel or no internet after all checks

Collect the ipconfig and ping results and contact support. Do not factory reset or reinstall the image yourself.

Contact support when

The panel still does not open, or the Mini PC has no DHCP or internet after the wiring checks.

Send us

  • H3000 or Mini PC, and the number of boxes
  • A screenshot of 192.168.5.1:9000
  • The ipconfig and ping results
  • A photo of the full cable setup

Fix: Not valid device

The app refuses the devices with a licence error. Two causes, one of which is simply a wrong clock.

The invalid device error in the GenFarmer app. Symptom: the app refuses the devices and shows a licence error.

Why it happens

  • You are signed in to the same GenFarmer account on more than one computer at the same time
  • You signed in on one computer and then signed in on another
  • The date, time or time zone on your computer does not match the real time

A GenFarmer account supports one email signed in on one computer at a time.

How to fix it

  1. Sign out everywhere

    Sign out of the GenFarmer account on every computer.

  2. Check the clock

    Check that the date, time and time zone match the real time in your region. If they do not, open Date and Time Settings, click Sync now, then check the time zone again. If your clock was already correct, go to step 3.

  3. Sign in on one computer only

    If the licence error is still there, select and delete every device shown in the control panel, close the application and open it again.

If you were never signed in anywhere else, do step 2 anyway - a wrong clock alone causes this error. If it persists, contact support.

Fix: Device not showing (Unauthorized)

Some phones never appear on screen because ADB reports them as unauthorized. Fixed with the ADB key file for your box model.

This is the main reason some phones in the box never show up on screen. The devices are connected, but ADB reports them as unauthorized, so GenFarmer cannot use them.

How to fix it

  1. Open Command Prompt

    Press Windows + R, type cmd and press Enter.

  2. Check the device status

    Type adb devices. Every device listed as unauthorized has this problem.

  3. Ask support for the ADB Key file

    The key depends on the Boxphone model you own, so contact GenFarmer support to get the right file. See Before you contact support for what to send them.

  4. Put the key in the right folder

    Go to C: drive → Users → your computer name → .android

  5. Replace the existing key

    Copy the ADB Key file from GenFarmer into that folder, choosing Replace if prompted.

  6. Restart the ADB server

    Back in Command Prompt, run the two commands below. When every device shows the status device, the problem is fixed.

adb kill-server
adb devices

If adb devices recognises nothing at all, ADB is not installed on your computer yet. Set up the ADB environment first - see ADB commands and the requirements on Requirements and safety notes.

Fix: Boxphone indicator light error

A red or flickering light is a hardware fault on one mainboard. How to tell the slot from the board.

Symptoms: the indicator light flickers or shows red, and the device drops out of the software.

The normal light code is blue for USB mode and green for OTG mode. Red or flickering is a hardware fault on that mainboard, not a software problem.

How to fix it

  1. Swap the mainboard to another slot

    Remove the mainboards that are misbehaving and swap their positions with others. This tells you whether the fault follows the slot or the mainboard.

  2. Reseat the FPC cable

    If the problem persists after the swap, adjust or reseat the FPC cable - the long orange ribbon running along the mainboard.

Reseating the FPC cable means opening the box. If you are not comfortable doing it, contact support first: hardware altered without guidance falls outside the warranty, as noted on Requirements and safety notes.

FAQ

The questions customers ask most often, with links to the page that answers each one in full.

The questions customers ask most often. Where a full page already answers one, this page links to it instead of repeating it.

Hardware and setup

What do I need to run a Boxphone system?

  • Hardware: a Boxphone, and optionally a router for IP security and network management
  • Software: the automation tools and scripts
  • Resources: an internet connection, social media accounts, and proxies or a VPN to give the devices different IP addresses

The full requirement list, including PC specification and voltage, is on Requirements and safety notes.

How can each device in a Boxphone have a different IP address?

Use a proxy or VPN per device. GenFarmer also sells GenRouter, which assigns the proxy or VPN quickly, spoofs network parameters such as MAC, DNS and WebRTC, and blocks LAN scanning. Why this matters for account survival is explained on Day 2, and everything about choosing the device and the proxies is on Router & proxy.

How many accounts can I run on one Boxphone?

  • Safest: 1 account per platform per device
  • You can push further, but the recommended maximum is 3 accounts per platform per device

Can I rent a Boxphone to try it first?

You can rent Cloudphone services from GenFarmer to test the system: Cloudphone GenFarmer for social media use, and Genplay.io for gaming or idle gaming.

Does it work with emulators as well as boxes?

Yes. GenFarmer describes itself as covering screen streaming and no-code automation for phone farms and emulators. There is a walkthrough for LDPlayer on the channel: How to connect LDPlayer with GenFarmer - automation on emulator.

What it can and cannot do

Can a Boxphone be used for gaming or idle gaming?

Yes, particularly for lightweight or idle games and simple automation such as auto check-in, pet raising or farming systems. Supported examples include Roblox, Play Together and Clash of Clans. Heavy games such as Lien Quan, Ymir or Raven2 need a Boxphone model with matching hardware.

Does GenFarmer teach how to make money with a Boxphone?

No. GenFarmer documents how to use the devices and software in its own ecosystem - operating, installing, optimizing and managing devices - so you can apply those tools to your own work.

Where do I start learning no-code automation?

GenFarmer runs free no-code automation courses, from basic to advanced, on the GenFarmer Vietnam YouTube channel. The features those courses use are described on Automation.

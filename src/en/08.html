Glossary

Terms that appear in the course and the HDSD, explained briefly the way the GenFarmer system uses them.

When you meet a term you do not know while reading, look it up here and then go back to the page you were on. Organized by the four layers of the system - see The four layers of the system.

Layer 1 · Device

TermMeaningFound in
Box / BoxphoneThe hardware enclosure holding many phones (usually 20), bought from GenFarmer.Layers · Day 1
GenFarmer SoftwareThe software installed on your computer to control every phone in the box. Download from genfarmer.com/download.Day 1
Control CenterThe manual control screen in the software: tap, type and act on one phone or many phones at once.Day 1
USB modeThe connection mode when using 1 box with a GenRouter H3000. Plug in and it is detected automatically.Day 1
OTG modeThe connection mode when using a mini PC. You must add two address ranges, click Active, then Scan. In this mode the phones already have internet through the mini PC.Day 1
Address rangeThe two network address ranges 192.168.4.1-255 and 192.168.5.1-255 that must be declared in OTG mode so the software can find the phones.Day 1
Active / ScanActive: activates the address ranges you added. Scan: searches for phones. Forgetting Active is the most common reason Scan finds no phones.Day 1
Device IDThe identifier of each phone, shown on the main screen; used to assign a phone to an account in Account Manager.Day 2
APKThe Android app installation file (TikTok, Facebook…). Installed in bulk with the Install APK button.Day 2
adbAndroid's command-line tool for sending commands directly to a phone. Optional, for people with a technical background only.Day 1

Layer 2 · Network

TermMeaningFound in
GenRouter (H3000)GenFarmer's router, which gives each phone its own internet route. The H3000 serves 1 box. Control panel at 192.168.5.1:9000.Layers · Day 1 · Day 2
Mini PCA small computer used instead of the H3000 when you have 2 or more boxes; the phones in the box use the mini PC's network (OTG mode). Needs a Cat5/Cat6 LAN cable.Day 0 · Day 1
ProxyAn account's "home address" on the internet. Each phone / each account needs its own proxy; sharing one is what causes accounts to get banned in clusters.Day 2
Isolate ModeA GenRouter mode: if a phone's proxy dies, that phone's network is cut immediately so the real address is never exposed.Day 2

Layer 3 · Identity

TermMeaningFound in
AccountAn account on a platform (TikTok, Facebook…). In the system, an account is an identity; the proxy is that identity's home address.Day 2
UID | Password | 2FAThe default format for entering accounts into the sheet: account ID, password and two-factor code, separated by vertical bars. Can be changed under Custom.Day 2
Account ManagerThe account management screen: where you import the account sheet, assign Device IDs, and (from Day 3) choose which account runs which script.Day 2 · Day 3
VerificationThe platform asks you to prove the account (OTP code, photo, video…). Being asked for verification more often than usual is a sign to stop.Day 2 · Day 4-5
Warming up / settling accountsThe 2-4 week phase in which an account builds habits like a real person before being used for its main purpose. Slow growth during this phase is normal.Day 2 · Day 3 · Day 4-5

Layer 4 · Automation

TermMeaningFound in
ScriptA recorded sequence of actions the phone performs on its own, running on many phones at once. No coding needed.Day 3
Automation package / StoreA ready-made set of scripts for each platform, downloaded from the Store section of the software.Layers · Day 3
Auto LoginThe bulk log-in / log-out tool.Day 3
TrustThe account warming-up tool: the phone watches, scrolls, likes and follows like a real person with clear interests. Runs for 2-4 weeks.Day 3
BoostThe tool that pushes engagement onto one specific post. Use only after enough warming up.Day 3
vilao.ai API keyThe key used for automatic commenting (AI-written comments). Prepare it on Day 0.Day 0 · Day 3

A 2-minute self-check before you message

Many cases can be solved on the spot:

What you are seeingQuick check
Scan finds no phonesDid you add both address ranges and click Active? → Day 1 · step 3
Phones show up but have no internetIs the proxy still alive? Is the time on the phone correct? → Day 1 · step 3
Many accounts get banned at the same timeAre any accounts sharing a proxy? → Day 2
A different app shows up after installingAre you downloading from the links in the User Manual (HDSD)? Use the official APK folder in Day 2 · step 3
Some phones never show up, or the light is redCheck Unauthorized and indicator light error first - both are fixed without support
The numbers do not moveHave you warmed up for the full 2-4 weeks? Did you pick the right niche? → Day 4-5

Full list: Troubleshoot by symptom.

The 5 pieces of information to include

  1. Number of boxes in use, and whether you use a GenRouter H3000 or a mini PC
  2. Whether you are connected over USB or OTG
  3. Which day of the roadmap you are on (Day 0-5) and which step you are doing
  4. How many phones Scan finds / how many phones are running
  5. A screenshot of the software at the moment of the error (and a screenshot of the phone if relevant)

Message template - copy, fill in, send

[GenFarmer support]
- Number of boxes: ... (H3000 / mini PC)
- Connection: USB / OTG
- Currently on: Day ... - step ...
- Scan finds: ... / ... phones
- Problem: (what you were doing, what you see on screen)
- Already tried: ...
- Screenshot: (attached)

A message with all 5 items above is usually resolved in a single reply, instead of going back and forth several times.

Hardware warranty

If you suspect a manufacturing defect, include the unboxing video you filmed on Day 0 (seals intact). This is your warranty evidence.

Setup

Change / Backup / Restore

Give each app its own device identity, and keep account data that survives a reset or a swap.

Change gives a device a new identity for each application. Backup and Restore keep the account data of an app so you do not have to log in again. The technology behind it is explained in What is Change / SuperChange.

Change Device - Back Up - Restore in GenFarmer

Change device

This feature lets you modify the device information seen by each application. In practice you can run two Telegram apps on the same phone and have each app see a different device.

  1. Select the device and open Change device

    Select the device, then click Change device in the side menu. The default identity is Samsung Galaxy S21 Ultra 5G.

  2. Randomise or set the parameters by hand

    Click Random to let the system randomise every parameter. To set them yourself, tick Manual in the top-right corner and adjust as you like.

  3. Confirm

    Click Change. The device disconnects and reboots briefly to apply the new settings.

  4. Verify

    Open the Device Info HW app to check the new identity - after the change the device may show up as Realme RMX2030. The app is a free download from APKPure.

Backup: social media account data

  1. Open the account you want to back up

    Go to the platform, open the account profile and check that everything is as it should be.

  2. Back up the app

    Close the app, hover over it (TikTok, for example) and select Backup App.

Restore: social media account data

  1. Choose Restore App

    With the backup file saved, return to the app and select Restore App.

  2. Pick the backup file

    Choose the file you saved earlier.

  3. Reopen the app

    Once you see Restore successful, close the app and open it again to carry on using it.

Backup and Restore are what make a swap painless: when you move an account to another device or reset one, you restore instead of logging in again and going through verification.

Control Center

The screen you use every day: the sidebar, the stream view, synchronized control and the Inspector.

The Control Center is where you spend most of your time: the grid of phones, the toolbar that tunes how they are displayed, the stream view of a single device, synchronized control, and the Inspector for anyone writing scripts.

Sidebar menu

The toolbar on the left of the control panel holds the functions for managing devices and adjusting how they look on screen.

Adjust device quality

  • Big Screen: the size of a device's stream window. Minimum 40%, maximum 100%
  • Small Screen: the size of the device tiles inside Control Devices - Thumbnail, Medium, Large or Extra Large
  • Big Quality: the image quality of the stream - Low, Medium, High or Extra (Extra gives the best experience)
  • Small Quality: the image quality of the tiles on the overview screen - Low, Medium, High or Extra

Device management

  • Select all: select every device to install APKs, stop tasks and so on
  • Select device: select individual devices to work on

To deselect one device while Select all is active, hold Ctrl and click it.

Stream Device

Stream Device shows a phone screen at the real size of the device, and streams every action smoothly.

  • Vol+ / Vol-: volume up and down
  • Screenshot: capture the device screen
  • Power: turn the screen off
  • Rotate: rotate the screen
  • Install APK: install an application straight from the stream
  • ADB Command: run additional ADB commands
  • Reboot: restart the device
  • Switch Keyboard Method: open the keyboard settings
  • Accessibility Settings: open the settings interface
  • Language: open the language settings
  • Connection Setting: open connection settings such as Wi-Fi and Bluetooth
  • Apps: show the applications installed on the device

Group Control

Group Control synchronizes the devices: you work on one device and the rest repeat the same actions.

Select the devices you want to synchronize.

Then open the stream of any one of them to make it the main device.

Work on that device and the others follow identically.

Group Control is free and has no limit on the number of actions. The step-by-step version of this, together with installing an app on every phone, is on Synchronized control and APK installation.

Inspector

Inspector retrieves package and element information from an application, for use when writing automation code. It opens as a separate window from the GenFarmer app.

Inspector toolbar

  • Select Devices: the dropdown listing every device currently connected to GenFarmer
  • Reload: reload the current screen of the device
  • Enable Grid: show the element grid to identify elements precisely
  • Enable Swipe: swipe the phone directly on the Inspector screen
  • Enable Crop: capture an image and convert it to Base64 for the Image search node

What the Inspector view shows

Hover the mouse over the device interface to reveal the element blocks. Click an element and the middle column fills with information about that element and the application.

The right-hand column of the stream view shows:

  • Activity: the action of the element
  • XPathLite: the XPath used for scripting
  • ClassName: the class name of the element
  • Mouse Pos: coordinates of the selected position
  • Click: click the element and reload the device screen automatically
  • Element Rect: coordinates of the element
  • Index: the priority order of the element
  • Text: the text the element contains
  • Resourceid: the ID of the element
  • Package: the package ID of the application
  • Description: the description of the element

You can also select elements through the code view of the application.

Account Manager

The account sheet inside the app: importing accounts, assigning devices, and choosing which account runs which script.

Account Manager keeps your account sheet inside the GenFarmer app, so you no longer need Excel or Google Sheets. In the roadmap you first use it on Day 2, and from Day 3 it is also where you choose which account runs which script.

Adding accounts

Add Accounts lets you add accounts by hand.

  • Please Input: the UID or username of the account
  • Select Format: a ready-made template per account type, or a custom one
  • Custom Format: choose the fields yourself - UID, Password, Email, 2FA and so on

Import and export

  • Export: export the account file in XLSX format
  • Import: import a CSV or XLSX file. GenFarmer ships a template file to work from

The columns

  • Device: the default device for that account
  • Status: the status of the account
  • UID: the username
  • Email: the email tied to the account
  • Password: the password
  • Email Password: the email password, used to read verification codes
  • 2FA: the authentication code

Once an account has been added, it runs on the device you selected, through whichever Module or App you use.

Assigning a device to an account is the step people skip. Copy the Device ID from the main screen into the Device ID column, otherwise the script has no phone to run on.

Devices

Which devices your account may use, which are active, and how many slots are left.

The Devices screen manages the devices attached to your account.

Device overview

  • Total: the number of devices the account may use

How to change app with GenFarmer: install apps via APK or Store

Installing from the Store

Besides APK files, you can install from the Store, which carries applications GenFarmer has checked for safety and compatibility with most devices.

Download, then select version is the whole flow.

Choose the version that matches the Android version of the device, or the installation will throw errors. The device-side steps are on Synchronized control and APK installation.

Automation

Apps, Modules, Tasks and Runs: how a script is built, stored, assigned to devices and tracked.

Automation is how the repetitive work moves from your hands to the machine, with the Antidetect features keeping the accounts alive. Whatever you run, there is a script for it: written by you, imported, or bought.

The day you start using it in the roadmap is Day 3, and the ready-made packages (Auto Login, Trust, Boost) are described there.

My Apps

  1. My App: the automations belonging to the account - written by you, imported, or bought from the store
  2. Subscription: the automations bought from the store, active and expired
  3. Import App: install an automation from a genfarmer file. Buy from the store or another source you trust, to avoid losing information
  4. Create App: create and write a new script
  • Select Devices: the device you want to test on
  • Select Node: the nodes that make no-code scripting possible
  • View Edit: shows the script and the nodes it uses
  • Top Bar: the supporting toolbars
  • Custom View: a custom cover image for the app
  • Device View: the device to stream
  • Table Column: design the data table for the information the script needs
  • Save: save the app and its nodes
  • Run: test the app on the selected device
  • Other functions: run logs, save as a different name, debug mode

My Modules

A Module is a more advanced form of an App, able to hold several smaller functions inside one Module. The interface and the functions are the same as Apps, with extra nodes for running several Apps inside the Module.

What sets a Module apart is the Context Menu node, which divides the functions and manages several Apps inside a single Module.

Saved Tasks

Saved Tasks holds the tasks you have already built, so running them again takes one click.

  • Name: the name of the task
  • App: the script app the task uses
  • Devices: how many devices run in the task
  • Runs: how many times it has run
  • Last run started at / Last run status / Last run duration: the most recent run

To create a task, go into a module or an app and choose Create Task.

Name the task, then pick the devices it should run on.

When you are done you can save and run it straight away, or save it for later.

Runs

Runs is where several tasks are managed at the same time.

  • App: the name of your script app
  • Task: the name of the task
  • Result: the number of runs
  • Started at / Finished at / Duration: when it ran and for how long
  • Status: Running, Done or Aborted
  • Run: run the task again

Tasks are created in Saved Tasks, and appear here once they are running.

Language, storage location and the automation switches such as debug mode.

Settings holds the basic configuration of the software.

General

Choose the language, and light or dark mode.

Automation

  • Sync Profiles Data After Running Task: synchronize profile data after a task finishes

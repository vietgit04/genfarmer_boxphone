Three common mistakes

✕MistakeCause / fix
1Scan finds no phonesAlmost always because both address ranges were not added, or they were added but Active was never clicked
2OTG is plugged in but the phone has no internetCheck the proxy first; if the proxy is fine, check the time on the phone

Day 2 - Mastering identity

Layers 2 + 3. The most important day of the week. You only touch 5 accounts, and most of the time is spent waiting.

Layer 2 · Router + Layer 3 · Account + Proxy

The most important day of the week - and the part the User Manual (HDSD) does not cover in depth. Read this page carefully.

Question of the day: Will my accounts survive?

Start small, start slow. Today you only touch 5 accounts, and most of the time is spent waiting.

Why accounts get banned in clusters

An account is an identity. A proxy is that identity's home address.

If 20 accounts share one address, the platform sees 20 people living in the same house, waking and sleeping at the same time, liking the same kind of content. That is why accounts get banned in clusters rather than one by one.

GenRouter exists so that each phone has its own address. Isolate Mode does one more thing: if a proxy dies, it cuts that phone's network immediately instead of letting the phone expose your real address.

✕ Wrong - 20 accounts, 1 address

1 proxy → Acct 1Acct 2… Acct 20

✓ Right - one address per phone

proxy 1→Acct 1
proxy 2→Acct 2
proxy …→Acct …
Prepare accounts + proxies → Assign proxies + Isolate Mode → Install the platform app → Log in by hand as a test → Import the account sheet → Run a simple job so the accounts get warmed up

Steps

  1. Prepare 5 accounts and 5 proxies

    If you want to save money for the trial, 5 accounts spread over 2-3 proxies is acceptable, but remember that this is not a real production setup.

  2. Assign a proxy to each phone and turn on Isolate Mode

    Open the GenRouter control panel at 192.168.5.1:9000, assign a proxy to each phone, and turn on Isolate Mode.

    Choosing and buying proxies, and what to do when the network drops: Router & proxy →

    How to use GenRouter: assign a proxy per device

    If it still does not work after following the video below, contact support before you log in to any account.

  3. Install the platform app on the phones

    Download the APK file, select all phones, and click Install APK. Step by step with screenshots: Synchronized control and APK installation. HDSD p. 17 · 51 · 78 · 102 · 124

    Install it on every phone today: Day 2 is when you start logging accounts in gradually to let them settle, so installing in advance saves work on the following days.

    Do not download the APK from the links in the HDSD. The APK links for Facebook, Instagram, X and Spotify in the HDSD are currently wrong (they point to the TikTok file). Download the APKs from the official folder below.

    Official APK folder (includes TikTok, Facebook, Instagram, X, Spotify): APK_GENFARMER - Google Drive

  4. Log in to 1-2 accounts by hand

    Go slowly and watch every step.

    This is the most important step of the whole week: the automation later only repeats exactly what you have just done by hand. If an account is already asked for verification when you do it by hand, the automation will hit the same thing, just 20 times faster.

  5. Create an account sheet in Account Manager

    Only do this once the 1-2 accounts from the previous step are stable. Every field and button on that screen is described in Account Manager. HDSD p. 10-11

  6. Enter all 5 accounts into the sheet

    The default format is UID|Password|2FA; to change it, go to Custom. HDSD p. 11-13

  7. Assign a device to each account

    Copy the Device ID from the main screen and paste it into the Device ID column. HDSD p. 14-15

  8. Leave everything alone for 48 hours

    Do not run anything. This is not dead time - this is the test.

Done when

5 out of 5 accounts can still log in after 48 hours, and none of them has been asked for verification or temporarily locked.

If you are not there yet, do not buy more accounts under any circumstances. Change your account supplier or change proxies, then retry from step 4 (log in by hand). Buying 20 accounts while 5 are still not surviving is the fastest way to waste money.

Three common mistakes

✕MistakeConsequence
1Buying 20 accounts right away to fill the whole setYou lose all 20 in a single night
2Sharing one proxy across many accounts to save moneyAccounts get banned in clusters, and you wrongly conclude the hardware is at fault
3Logging in to many accounts on the same phone one after another in a short timeNo real person does that

Day 3 - Basic automation

Layer 4. Today you do not learn a new feature - you simply hand over to the machine the things you did by hand over the past two days.

Layer 4 · Automation

Question of the day: Can the machine do the work for me?

Today you do not learn a new feature. You simply hand over to the machine the things you did by hand over the past two days.

What automation is

It is the very same actions you tapped by hand on Day 1 and Day 2, recorded as a script and run on many phones at once. No coding needed; you just select and click.

ToolWhat it doesWhen to use it
Auto LoginLogs in and logs out in bulk instead of typing on each phone by handToday
Trust (warming up accounts)The phone watches videos, scrolls, likes and follows like a real person with clear interests. The goal is for the platform to register this account as belonging to someone with habits, not a brand-new account.Run for 2-4 weeks
Boost (boosting engagement)Concentrates engagement on one specific post so the platform distributes it more widelyOnly after enough warming up

Package by package, with the figures to run each one by: Automation packages →

Turning on Boost on an account that has not been warmed up is the fastest way to lose it, and an account that has once run junk engagement is very hard to recover.

Download the automation package → Run Auto Login → Turn on Trust to warm up accounts

Steps

  1. Check that the platform app is on the phones

    The platform app was installed on Day 2 · step 3. Install it on any phone that is missing it, following the instructions there - download from the official APK folder, not the links in the User Manual (HDSD).

  2. Download the automation package for your platform

    Go to the Store - see App Manager for the Store itself and Automation for how Apps, Tasks and Runs fit together - find your package and download it. A video guide is included - see the GenFarmer video playlist. HDSD p. 18-20 · 52-55 · 80-83

  3. Download the platform's three tools

    Auto Login, Trust and Boost. HDSD p. 21-24 · 56-59 · 84-88

  4. Open the Account Manager screen

    This is where you choose which account runs which script. On Day 2 you used this screen to store accounts; today you use it to give orders.

  5. Run Auto Login on exactly the 5 accounts you already have

    Do not scale up yet.

  6. Turn on Trust for those 5 accounts

    Let it run overnight.

  7. Check the next morning

    If all 5 are still alive, buy more to reach 20, then run Auto Login and Trust on all 20 phones.

Done when

20 phones log in on their own and warm up accounts overnight without you having to step in.

If any account gets banned overnight, do not scale up. Go back and check the proxies and the running speed first.

Three common mistakes

✕MistakeConsequence
1Turning on Boost on the first day because you want to see results earlyThe most expensive mistake in the whole roadmap
2Running at full capacity on the first run instead of ramping up graduallyAccounts get banned in bulk
3Only discovering you have no vilao.ai API key when you reach automatic commentingYou have to stop halfway. This was already part of Day 0. Note: even with the right API, if the provider's model has an outage, automatic commenting may still be affected
